# Security

If you find a security problem (for example a way to read another user's
data, bypass the comment or payment checks, or reach `/admin`), please do not
open a public issue. Report it privately through GitHub's
"Report a vulnerability" button on this repository, or through
https://jobseekers.imswarnil.com/contact.

I will reply within a week and credit you in the fix if you would like.

Never commit secrets. `.env` is gitignored; `.env.example` lists every
variable with no values.
