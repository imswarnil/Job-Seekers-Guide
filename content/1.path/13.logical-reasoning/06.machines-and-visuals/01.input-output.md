Critical reasoning was about arguments. Input-output is about procedures: a
machine follows a fixed rule, one step at a time, and you have to work out the
rule from one example and run it on a new input. If you have written a sorting
loop in the Java track, you already know this shape.

## Why it matters

Input-output (sometimes called machine input or rearrangement) appears in
Infosys, Capgemini and bank-style reasoning sections, usually as a set of three
to five questions on one machine. TCS NQT and AMCAT-style tests use it less.
Check the current pattern. A set takes about three minutes when the rule is
clear, and it is one of the sets worth leaving if the rule does not show itself
in the first minute.

## What to study

| # | Rule type | Priority |
| --- | --- | --- |
| 1 | Sorting numbers, one placed per step (ascending or descending) | High |
| 2 | Sorting words alphabetically, one placed per step | High |
| 3 | Mixed: a word from the left and a number from the right each step | Medium |
| 4 | Arithmetic change each step (add 3, reverse digits) | Medium |
| 5 | Shifting: each step moves elements by a fixed number of places | Low |

## The method

::steps
### Compare input with step I only
What moved? Where did it go? What stayed in the same order?

### Name the rule in one sentence
"Each step, the largest remaining number moves to the left, and the rest keep
their order." Write the sentence down.

### Check it on step II and step III
If the sentence predicts both, you have the rule. If not, look again before
going further.

### Note the last step
How many steps did the example take? That usually answers one question
directly.
::

::tip
Most sorting machines place exactly one element per step. So a line of six
elements is finished in at most five steps, fewer if something is already in
place. Count the steps of the example; it confirms your rule.
::

## A worked example

**Input:** `17 42 9 85 30 61`

```text
Step I:   85 17 42 9 30 61
Step II:  85 61 17 42 9 30
Step III: 85 61 42 17 9 30
Step IV:  85 61 42 30 17 9
```

::accordion
  :::accordion-item{label="Find the rule" icon="i-lucide-search"}
  Input to step I: 85, the largest, moved to the front. The others kept their
  order: `17 42 9 30 61`.

  Step I to step II: 61, the largest of the rest, moved to second place. The
  others kept their order.

  **Rule:** each step, the largest number not yet placed moves to the next
  position from the left; the rest shift right, keeping their order. Step IV is
  fully sorted, so the machine stops there.
  :::
  :::accordion-item{label="Run it on a new input" icon="i-lucide-play"}
  **Input:** `23 71 48 5 96 34`. What is step II, and how many steps to finish?

  ```text
  Step I:   96 23 71 48 5 34
  Step II:  96 71 23 48 5 34
  Step III: 96 71 48 23 5 34
  Step IV:  96 71 48 34 23 5
  ```

  **Step II: `96 71 23 48 5 34`. Four steps.**
  :::
::

::note
Word machines work the same way with the alphabet. Watch for how a paper
treats capital letters, and for words that start with the same letter; the
example always tells you, so check it before assuming.
::

## Common mistakes

- **Guessing the rule from the final step.** The final step hides the order in
  which things moved. Compare consecutive steps.
- **Swapping instead of shifting.** Many machines insert and shift; some swap
  two elements. The example decides which.
- **Assuming the step count** for a new input equals the example's. If an
  element is already in place, the machine usually skips it and finishes
  sooner.
- **Rewriting every element every step.** Only write what changed; copy the
  rest with a line.

## How to practise

- **Week one:** one machine set a day from IndiaBix "Machine Input" or a bank
  reasoning book (R.S. Aggarwal covers the older style), untimed.
- **Week two:** two sets a day, target **3 minutes per set**.
- **Before a drive:** PrepInsta's company pages, to see whether that company
  uses number, word or mixed machines.

## Practice questions

Use the rule from the worked example.

::accordion
  :::accordion-item{label="1. Input: 12 50 33 8 41. What is step I?"}
  **`50 12 33 8 41`.** 50 moves to the front.
  :::
  :::accordion-item{label="2. Same input. What is step II?"}
  **`50 41 12 33 8`.** 41 moves to second place.
  :::
  :::accordion-item{label="3. Same input. How many steps to finish?"}
  **Three.** Step III is `50 41 33 12 8`, fully sorted.
  :::
  :::accordion-item{label="4. Input: 90 70 50 30 10. How many steps?"}
  **None.** It is already in descending order, so the machine has nothing to
  do.
  :::
::
