Coding-decoding was about a rule that turns one word into another. An analogy
is the same idea with meaning instead of letters: two things are related in
some way, and you find the thing that is related to a third in the same way.
Odd one out (also called classification) is its mirror: four things share a
rule and one does not.

## Why it matters

Analogies and classification appear in Wipro, Capgemini, TCS NQT and
AMCAT-style papers, and in the verbal section of some papers as word
analogies. Expect roughly one to three questions between them, and check the
current pattern. They are 20-second questions once you have the habit below.

## What to study

| # | Type | Example |
| --- | --- | --- |
| 1 | Word analogy | `Doctor : Hospital :: Teacher : ?` |
| 2 | Number analogy | `3 : 27 :: 5 : ?` |
| 3 | Letter analogy | `ACE : BDF :: GIK : ?` |
| 4 | Word odd one out | `Mango, Apple, Potato, Banana` |
| 5 | Number odd one out | `16, 25, 36, 48, 64` |
| 6 | Letter-pair odd one out | `BD, FH, JL, NQ` |

## The relationships that come up

Most word analogies use one of these. Learn to name them.

| Relationship | Example |
| --- | --- |
| Worker : workplace | Doctor : Hospital |
| Worker : tool | Carpenter : Saw |
| Tool : action | Pen : Write |
| Creator : creation | Author : Book |
| Part : whole | Page : Book |
| Young one : adult | Puppy : Dog, Calf : Cow |
| Raw material : product | Cotton : Cloth |
| Cause : effect | Fire : Smoke |
| Synonym / antonym | Big : Large, Hot : Cold |
| Unit : quantity | Kilogram : Mass, Metre : Length |

## The method

::steps
### Say the relationship as a sentence
"A doctor works in a hospital." Not "they are connected".

### Put the third item into the same sentence
"A teacher works in a ___." The blank answers itself: school.

### If two options fit, make the sentence stricter
"A doctor works in a hospital, treating patients." Now test again.
::

For **odd one out**, reverse it: find the rule that **four** share, then the
one that breaks it.

::warning{icon="i-lucide-alert-triangle"}
With small numbers you can always find some reason for each option to be odd.
The rule shared by four of the five is the rule. Stop looking once you have it.
::

## A worked example

::accordion
  :::accordion-item{label="Number analogy" icon="i-lucide-hash"}
  **3 : 27 :: 5 : ?**

  `27 = 3³`. So the answer is `5³` = **125**. Check the alternatives the options
  offer: `3 × 9 = 27` would give 45. Prefer the rule that uses only the first
  number (cube) over one that needs an extra constant (× 9).
  :::
  :::accordion-item{label="Letter analogy" icon="i-lucide-type"}
  **ACE : BDF :: GIK : ?**

  Each letter moves forward by one: A→B, C→D, E→F. So G→H, I→J, K→L.

  **Answer: HJL.**
  :::
  :::accordion-item{label="Letter-pair odd one out" icon="i-lucide-search-x"}
  **BD, FH, JL, NQ**

  ```text
  B2 D4 → gap 2
  F6 H8 → gap 2
  J10 L12 → gap 2
  N14 Q17 → gap 3
  ```

  **Answer: NQ.**
  :::
::

## Common mistakes

- **Reversing the order.** `Doctor : Hospital` is worker then place. An option
  with place then worker is wrong even if the pair is right.
- **Picking an answer that is related, but differently.** "Teacher : Student"
  is a real relationship, not this one.
- **Using general knowledge where a simpler rule exists.** Look for squares,
  cubes and primes before trivia.
- **Choosing the first odd feature** in odd-one-out questions without checking
  it separates exactly one item.

## How to practise

- **Days one and two:** 15 questions a day from IndiaBix "Analogies" and
  "Classification" (both under verbal reasoning). Target **20 seconds**.
- **Write the relationship sentence** for every word analogy, even the obvious
  ones, for the first 50 questions. After that it happens in your head.
- R.S. Aggarwal's reasoning book has good number and letter analogy sets.

## Practice questions

::accordion
  :::accordion-item{label="1. Pen : Write :: Knife : ?"}
  **Cut.** Tool : its action.
  :::
  :::accordion-item{label="2. 4 : 16 :: 7 : ?"}
  **49.** Square.
  :::
  :::accordion-item{label="3. Odd one out: 11, 13, 17, 21, 23"}
  **21.** The others are prime; `21 = 3 × 7`.
  :::
  :::accordion-item{label="4. Odd one out: January, March, June, July, August"}
  **June.** It has 30 days; the others have 31.
  :::
  :::accordion-item{label="5. BCD : YXW :: FGH : ?"}
  **UTS.** Opposite letters: B↔Y, C↔X, D↔W, so F↔U, G↔T, H↔S.
  :::
  :::accordion-item{label="6. Odd one out: Mercury, Venus, Moon, Mars"}
  **Moon.** The others are planets.
  :::
::
