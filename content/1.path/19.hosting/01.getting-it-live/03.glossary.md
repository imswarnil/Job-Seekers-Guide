| Term | In one line |
| --- | --- |
| **`A` record** | A name → an IPv4 address. |
| **`CNAME`** | A name → another name. How a CDN sits in front of you without changing addresses. |
| **TTL** | How long a DNS answer may be cached. **Lower it before** a migration, not after. |
| **Let's Encrypt** | Free certificates, issued and renewed automatically. The automatic part is the one that matters. |
| **Environment variable** | Configuration from outside the code. Where every secret lives; never in git. |
| **`.env.example`** | The names with no values, committed. The difference between a fifteen-minute setup and an afternoon. |
| **Blue-green / rolling deploy** | Start the new one beside the old, switch traffic, keep the old briefly. No downtime, and a rollback is a switch. |
| **Rollback** | Going back to the previous version. A rollback you have never performed is a rollback you do not have. |
| **Migration** | A change to the database schema. **The part that cannot be rolled back**, which is why it is additive across several deploys. |
| **Health check** | An endpoint returning 200 only if the dependencies answer. One that returns 200 unconditionally is worse than none. |
| **Uptime monitor** | Something outside your infrastructure checking that endpoint and telling you before a user does. |
| **Structured logging** | Logs with fields and a request id, so one request can be followed. Logs you cannot search are logs you do not have. |
| **Observability** | Requests per minute, error rate, latency, connections. Four numbers that say which layer is wrong. |
| **Database branch** | A copy-on-write copy of production data, per pull request. Where a migration should fail. |

## The four sentences to keep

::pull-quote
A secret committed to git is compromised; rotate it, do not delete the commit.
Never drop a column in the same deploy that stops using it. A health check must
check its dependency. And roll back first, then diagnose.
::
