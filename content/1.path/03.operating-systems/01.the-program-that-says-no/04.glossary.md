Before the processes, the words. Only this chapter's, one line each.

| Term | In one line |
| --- | --- |
| **Kernel** | The core of the operating system: the code that actually owns the processor, the memory and the devices. Not a process, and it never appears in `ps`. |
| **User mode** | The processor state your programs run in. The instructions that would touch hardware directly do not work here. |
| **Kernel mode** | The processor state the kernel runs in, where every instruction works. Also called supervisor or privileged mode. |
| **System call** | The only doorway from user mode into the kernel. Everything your program cannot do itself: `read`, `write`, `open`, `fork`, `exit`. |
| **Trap** | The instruction that performs the switch into kernel mode. Deliberate, unlike an interrupt. |
| **Interrupt** | The hardware equivalent: a device says "I have finished", the processor stops whatever it was doing and runs kernel code. |
| **Context switch** | Saving one program's registers and loading another's. The cost of sharing one processor, and the subject of the next chapter. |
| **Firmware** | Code on a chip on the motherboard. UEFI or BIOS. Runs before there is an operating system at all. |
| **Bootloader** | The small program that finds a kernel on disk and loads it into memory. GRUB is the common one on Linux. |
| **Process 1** | The first user-mode process the kernel starts, and the ancestor of every other. `systemd` on most Linux, `launchd` on macOS. |
| **Orphan** | A process whose parent exited first. It is re-parented to process 1, which is written to collect it. |
| **Zombie** | A process that has exited but whose exit status nobody has read. Holds no memory, only a row in the process table. Thousands of them fill the table. |
| **Exit status** | The number a program returns when it finishes. `0` means success, anything else is a failure. Read it with `echo $?`. |
| **Buffer** | A block of memory in *your* program that holds data so you do not have to cross the kernel door for every byte. |
| **Privileged port** | A port below 1024. Binding to one needs elevated privilege, which is why a plain user cannot start something on port 80. |

either does it or refuses.
