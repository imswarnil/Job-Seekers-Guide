Sixteen weeks of Java in one page of words.

## The language and the platform

| Term | In one line |
| --- | --- |
| **JDK / JRE / JVM** | Development kit (compiler + tools) contains the runtime (library) contains the virtual machine (executes bytecode). You install the JDK. |
| **Bytecode** | What `javac` produces. Not machine code: instructions for a machine that does not physically exist. |
| **JIT** | The compiler that turns frequently-run bytecode into real machine code while the program runs. Why your first timing is misleading. |
| **Class / object** | A description written once; one actual instance of it with its own fields. |
| **`static`** | Belongs to the class, not to an object. One per class **per process**. |
| **`final`** | Assigned once. On a field, it cannot change; on a variable, it cannot be reassigned. |
| **Package** | A namespace and a visibility boundary. `com.university.admissions`. |
| **Garbage collection** | Reclaims objects that can no longer be **reached** from a root. Not "no longer needed". |

## Types and memory

| Term | In one line |
| --- | --- |
| **Primitive** | One of eight types holding a value directly. `int`, `long`, `double`, `boolean` are the four that matter. |
| **Reference** | What an object variable actually holds: the address of an object on the heap. |
| **Stack** | Per thread. Method frames, parameters, local variables. Exhaust it → `StackOverflowError`. |
| **Heap** | Shared. Every object made with `new`. Exhaust it → `OutOfMemoryError`. |
| **Integer division** | `7 / 2` is `3`. The operand types decide the arithmetic, not what you assign into. |
| **Floating point** | `0.1 + 0.2` is `0.30000000000000004`. **Never use it for money.** |
| **Autoboxing** | Automatic conversion between `int` and `Integer`. A null `Integer` unboxed is an NPE on a line with no dot. |
| **Pass by value** | Always. For an object, the value copied is the reference, which is why the method can mutate the object and cannot replace the caller's variable. |
| **Immutable** | Cannot change after construction. `String` and records are. Safe as map keys and across threads. |
| **String pool** | Identical string literals share one object, which is why `==` is intermittently true and therefore dangerous. |

## Objects

| Term | In one line |
| --- | --- |
| **Constructor** | Runs after the fields get their defaults. Your chance to make the object valid before anyone can use it. |
| **`this`** | The object the method was called on. Also `this(...)` to call another constructor, which must be first. |
| **`super`** | The parent. `super(...)` must be the first statement in a constructor. |
| **Invariant** | A fact that is true from construction until destruction. What encapsulation exists to protect. |
| **Encapsulation** | Private fields and controlled ways in, so exactly one place can break each rule. |
| **Inheritance** | `extends`. One parent only. Use it when "a Y **is a** X" is true of every Y, forever. |
| **Composition** | A field instead. Use it when "a Y **has a** X". Usually the better answer. |
| **Polymorphism** | One call, different behaviour depending on the object actually there. |
| **Dynamic dispatch** | The mechanism: the declared type decides what you may call, the actual object decides what runs. |
| **Overloading** | Same name, different parameters. Resolved at **compile** time. |
| **Overriding** | A subclass replaces a parent method. Resolved at **run** time. Always write `@Override`. |
| **Hiding** | What happens with `static` methods. Not overriding, because dispatch needs an object. |
| **Abstract class** | Cannot be instantiated. Has state and a constructor. Use for shared **state**. |
| **Interface** | A contract with no state. As many as you like. Use for shared **capability**. Prefer it. |
| **`default` method** | A method body on an interface, so the interface can grow without breaking implementors. |
| **Functional interface** | One abstract method, so a lambda can implement it. |
| **Record** | A one-line immutable data carrier with `equals`, `hashCode` and `toString` generated. |
| **equals / hashCode contract** | Equal objects **must** hash equally, or a map looks in the wrong bucket for an entry sitting in it. |

## Failure

| Term | In one line |
| --- | --- |
| **Checked exception** | The compiler forces you to handle or declare it. An environmental failure the caller can act on. |
| **Unchecked / `RuntimeException`** | Not enforced. Means a bug in the code. |
| **`Error`** | `OutOfMemoryError`, `StackOverflowError`. Never catch one. |
| **Stack trace** | Where it was noticed, then how it got there, most recent first. The bug is usually further down. |
| **`Caused by`** | The original exception under a wrapped one. The **last** one is usually the real problem. |
| **`finally`** | Runs whether or not an exception was thrown. Not run on `System.exit()`. |
| **try-with-resources** | Closes anything `AutoCloseable` automatically, in reverse order, even on an exception. |
| **`Optional`** | A return type saying "this might be absent". Not for fields or parameters. |

## Collections

| Term | In one line |
| --- | --- |
| **`ArrayList`** | The default list. Contiguous, O(1) by index, amortised O(1) to append. |
| **`HashMap`** | The default map. O(1) average, no defined order. |
| **`TreeMap`** | Sorted. O(log n). Use when you need ranges or ordered iteration. |
| **`ArrayDeque`** | The real stack and the real queue. Not `Stack`, which extends `Vector`. |
| **`Vector` / `Hashtable` / `Stack`** | Legacy, synchronised, avoid in new code. |
| **Generics** | `List<Applicant>`. Moves type errors from run time to compile time and removes casts. |
| **Type erasure** | Generics exist only at compile time. Why `new T[10]` is impossible. |
| **Stream** | A pipeline over a collection. Best for filtering, mapping and grouping. |
| **`computeIfAbsent` / `merge`** | Replace the most-written five lines in Java: get, create if absent, put back. |

## Testing

| Term | In one line |
| --- | --- |
| **JUnit** | The test framework. `@Test`, and assertions that fail loudly. |
| **Arrange, act, assert** | The shape of every test. Two "act" steps means two tests. |
| **Boundary test** | The value where the rule changes. Exactly 75 against a cutoff of 75. |
| **Parameterised test** | One test, many inputs, each failure naming its value. |
| **Coverage** | A useful signal and a terrible target. Easy to reach 90% while asserting nothing. |

## The seven sentences to keep

::pull-quote
The operand types decide the arithmetic. Never store money in a double. An object
variable holds an address, and Java is always pass by value. Compare strings with
equals. Equal objects must hash equally. Prefer an interface, and prefer
composition. And a test that has never failed proves nothing.
::
