JUnit was the last new idea. From here the job is revision, and revision starts
with words: every term in the track, one plain line each, in the order you met
them. This is the page to read on the bus to a walk-in.

::tip
Cover the right-hand column and say each definition out loud before you read
it. If you cannot say it in one sentence, go back to that lesson. The technical
round is spoken, not written.
::

## First steps

| Term | In one line |
| --- | --- |
| **JDK** | Java Development Kit: what you install. Contains the compiler (`javac`), tools, and the JRE. |
| **JRE** | Java Runtime Environment: enough to run a program (the JVM plus the standard library), not to compile one. |
| **JVM** | Java Virtual Machine: runs bytecode, manages memory and runs the garbage collector. One per operating system, same bytecode everywhere. |
| **Bytecode** | What `javac` produces in a `.class` file. Instructions for the JVM, not for a real CPU. |
| **JIT compiler** | The part of the JVM that compiles frequently-run bytecode into real machine code while the program runs. |
| **Write once, run anywhere** | The same `.class` file runs on any machine with a JVM. |
| **`main` method** | `public static void main(String[] args)`: where the JVM starts your program. |
| **Variable** | A named piece of memory with a declared type. |
| **Primitive type** | One of eight types that hold a value directly: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`. |
| **Literal** | A value written in code: `78`, `4_500_000L`, `'A'`, `"Anita"`. |
| **Integer overflow** | Going past an `int`'s maximum wraps round to a large negative number, silently. |
| **Widening** | Converting to a larger type (`int` to `long`). Automatic and safe. |
| **Narrowing** | Converting to a smaller type (`double` to `int`). Needs a cast and can lose data. |
| **Type cast** | `(int) 81.67`: forcing a conversion. Truncates, does not round. |
| **Numeric promotion** | `byte`, `short` and `char` become `int` before arithmetic, which is why `byte + byte` is an `int`. |
| **Short-circuit** | The logical AND (`&&`) and OR operators stop as soon as the answer is known, so the right side may never run. |
| **Compound assignment** | `+=`, `-=` and friends. They include a hidden cast back to the left-hand type. |
| **`Scanner`** | Reads typed input or text from a source. `nextInt` leaves the newline behind, which trips the next `nextLine`. |
| **`var`** | Lets the compiler infer a local variable's type. Still strictly typed. |

## Strings

| Term | In one line |
| --- | --- |
| **`String`** | An immutable sequence of characters. An object, not a primitive. |
| **Immutable** | Cannot change after it is created. Every "change" to a String makes a new one. |
| **String pool** | A shared set of String objects for literals, so identical literals are one object. |
| **`intern()`** | Returns the pooled copy of a String, adding it to the pool if needed. |
| **`==` on objects** | Compares references (the same object), not contents. |
| **`equals`** | Compares contents, if the class overrides it. `String` does. |
| **`StringBuilder`** | A mutable, unsynchronised sequence of characters. Use it to build text in a loop. |
| **`StringBuffer`** | The older, synchronised version of `StringBuilder`. Rarely the right choice now. |

## Control flow and arrays

| Term | In one line |
| --- | --- |
| **Condition** | An expression that is `true` or `false`. Java will not accept a number instead. |
| **Ternary operator** | `condition ? a : b`: a one-line `if` that produces a value. |
| **Fall-through** | In the old `switch`, a missing `break` runs into the next case. |
| **Switch expression** | The arrow form `case X ->`: no fall-through, returns a value, exhaustive over an enum. |
| **`yield`** | Gives a value from a block inside a switch expression. |
| **Enhanced for** | `for (int m : marks)`: every element, no index, no off-by-one. |
| **`do-while`** | A loop whose body always runs at least once. |
| **Labelled break** | `break outer;` leaves an outer loop from inside an inner one. |
| **Off-by-one error** | A loop that runs one time too many or too few, usually `<=` instead of `<`. |
| **Array** | A fixed number of values of one type, side by side, indexed from 0. |
| **`length`** | An array's size: a field, no brackets. (`length()` is String's; `size()` is a collection's.) |
| **2D array** | An array of arrays: `int[r][c]`. |
| **Jagged array** | A 2D array whose rows are different lengths. |
| **Shallow copy** | A copy of the outer container that still shares the inner objects. |

## Methods

| Term | In one line |
| --- | --- |
| **Method** | A named block of code with parameters and a return type. |
| **Parameter / argument** | The variable in the definition / the value passed in the call. |
| **Method signature** | Name plus parameter types. The return type is not part of it. |
| **Overloading** | Same name, different parameter lists. Chosen at compile time. |
| **Scope** | Where a variable can be used. A local variable exists only inside its block. |
| **Pass by value** | Java always copies the argument's value into the parameter. For an object, the value is a reference. |
| **Reference** | What an object variable holds: the address of an object on the heap. |
| **`null`** | A reference that points at nothing. |
| **Stack** | Per-thread memory for method frames, parameters and local variables. |
| **Heap** | Shared memory where every object and array lives. |
| **Stack frame** | The block of stack one method call uses. Gone when the method returns. |
| **Varargs** | `int... marks`: any number of arguments, received as an array. Must be the last parameter. |
| **Recursion** | A method that calls itself on a smaller version of the problem. |
| **Base case** | The input small enough to answer without recursing. Without one: `StackOverflowError`. |

## Classes and OOP

| Term | In one line |
| --- | --- |
| **Class** | A template describing fields and methods. Written once. |
| **Object / instance** | One thing made from a class with `new`, with its own copy of the fields. |
| **Constructor** | Runs when an object is created, to make it valid. Same name as the class, no return type. |
| **Default constructor** | The no-argument constructor Java adds only if you write none. |
| **Constructor chaining** | `this(...)` calls another constructor of the same class; `super(...)` calls the parent's. Either must be first. |
| **`this`** | The current object. |
| **`static`** | Belongs to the class, not to an object. One copy, shared. |
| **Static block** | Runs once, when the class is first loaded. |
| **Instance block** | Runs for every new object, before the constructor body. |
| **`final`** | A variable assigned once; a method that cannot be overridden; a class that cannot be extended. |
| **Encapsulation** | Private fields with controlled methods, so the object guards its own rules. |
| **Invariant** | A rule about an object that is always true, such as "marks are between 0 and 100". |
| **Getter / setter** | Methods that read / change a private field. A setter should validate. |
| **Inheritance** | `extends`: a class takes the fields and methods of a parent. One parent only. |
| **`super`** | The parent class: `super.method()` or `super(...)`. |
| **IS-A / HAS-A** | Inheritance / composition. A `Student` IS-A person; a `Student` HAS-A `Address`. |
| **Composition** | Holding another object as a field instead of inheriting from it. Usually preferred. |
| **Polymorphism** | One call, different behaviour depending on the actual object. |
| **Compile-time polymorphism** | Overloading: the compiler picks the method from the argument types. |
| **Runtime polymorphism** | Overriding: the JVM picks the method from the object's real class. |
| **Dynamic dispatch** | The mechanism behind runtime polymorphism. |
| **Overriding** | A subclass replaces a parent's method with the same signature. Mark it `@Override`. |
| **Method hiding** | A static method with the same signature in a subclass. Not overriding. |
| **Covariant return type** | An overriding method may return a subtype of the parent's return type. |
| **Upcasting / downcasting** | Treating a subclass object as its parent (automatic) / back again (needs a cast, can fail). |
| **`ClassCastException`** | A downcast to a type the object is not. |
| **`instanceof`** | Checks an object's type. `if (x instanceof Student s)` also casts it. |
| **Abstraction** | Showing what something does and hiding how. |
| **Abstract class** | Cannot be instantiated; may have fields, constructors, and abstract and concrete methods. |
| **Interface** | A contract of methods a class promises to provide. A class can implement many. |
| **`default` method** | An interface method with a body, so an interface can grow without breaking implementers. |
| **Marker interface** | An interface with no methods, used as a tag: `Serializable`, `Cloneable`. |
| **Access modifiers** | `private`, default (package-private), `protected`, `public`: who can see a member. |
| **Package** | A folder-like namespace for classes, and a visibility boundary. |
| **`import`** | Lets you use a class from another package by its short name. |
| **`equals` / `hashCode` contract** | Equal objects must have equal hash codes. Override both or neither. |
| **`toString`** | Returns a text form of an object. The default prints `ClassName@hash`. |
| **Record** | `record Student(int roll, String name)`: an immutable data class with constructor, accessors, `equals`, `hashCode` and `toString` generated. |
| **Wrapper class** | An object version of a primitive: `Integer`, `Double`, `Boolean`, `Character`… |
| **Autoboxing / unboxing** | Automatic conversion from `int` to `Integer` / back. Unboxing `null` throws NPE. |
| **Integer cache** | `Integer.valueOf` reuses objects for -128 to 127, so `==` is true there and false outside. |

## Exceptions

| Term | In one line |
| --- | --- |
| **Exception** | An object describing something that went wrong, thrown to stop normal flow. |
| **`Throwable`** | The root: `Error` and `Exception` extend it. |
| **`Error`** | A problem in the JVM, such as `OutOfMemoryError`. Do not catch it. |
| **Checked exception** | The compiler forces you to catch or declare it (`IOException`, `SQLException`). |
| **Unchecked exception** | A `RuntimeException` and its subclasses. Not enforced; usually a bug. |
| **`throw` / `throws`** | Throws an exception object / declares that a method may throw one. |
| **`finally`** | Runs whether or not an exception was thrown. Skipped only if the JVM stops (`System.exit`). |
| **Multi-catch** | One `catch` block for several exception types, separated by a vertical bar. |
| **try-with-resources** | `try (resource)`: closes it automatically, in reverse order. Needs `AutoCloseable`. |
| **Suppressed exception** | An exception thrown while closing a resource after another was already thrown; attached to the first. |
| **Custom exception** | Your own class extending `Exception` or `RuntimeException`, named for the problem. |
| **Exception chaining** | Wrapping one exception in another as its cause, so the original is not lost. |
| **Stack trace** | The chain of method calls when the exception happened, most recent first. |
| **`NullPointerException`** | Using a reference that is `null`. Java 14+ names the null part in the message. |
| **Helpful NPE message** | `Cannot invoke "String.length()" because "<local1>" is null`: which reference was null. |

## Collections and generics

| Term | In one line |
| --- | --- |
| **Collections framework** | The standard interfaces (`List`, `Set`, `Queue`, `Map`) and their implementations. |
| **`Collection` / `Collections`** | The root interface / a utility class of static helpers (`sort`, `max`, `unmodifiableList`). |
| **`List`** | Ordered, allows duplicates, access by index. |
| **`ArrayList`** | A list backed by a growable array. Fast by index; grows by about 1.5 times when full. |
| **`LinkedList`** | A doubly linked list. Cheap insert at the ends, slow by index. |
| **`Set`** | No duplicates. |
| **`HashSet`** | A set backed by a `HashMap`. No order. |
| **`LinkedHashSet`** | A `HashSet` that remembers insertion order. |
| **`TreeSet`** | A sorted set. O(log n) operations. |
| **`Map`** | Keys to values. Keys are unique. Not a `Collection`. |
| **`HashMap`** | A map using hash buckets. O(1) average, no order, one `null` key allowed. |
| **Bucket** | One slot of a `HashMap`'s internal array; entries whose hashes land there share it. |
| **Hash collision** | Two different keys landing in the same bucket. Normal, handled with a list or tree. |
| **Treeify** | Since Java 8, a bucket with more than 8 entries becomes a red-black tree. |
| **Load factor** | How full a `HashMap` may get (0.75 by default) before it doubles its capacity and rehashes. |
| **`LinkedHashMap`** | A `HashMap` that keeps insertion (or access) order. |
| **`TreeMap`** | A sorted map. O(log n). |
| **`Hashtable`** | The legacy synchronised map. No `null` keys or values. Avoid. |
| **`Iterator`** | An object that walks a collection: `hasNext`, `next`, `remove`. |
| **Fail-fast** | An iterator that throws `ConcurrentModificationException` if the collection changes under it. |
| **Fail-safe** | An iterator over a copy or a concurrent collection that does not throw. |
| **`Comparable`** | A class's natural order: `compareTo`, one per class. |
| **`Comparator`** | A separate ordering object: `compare`, as many as you like. |
| **Generics** | `List<Student>`: type parameters checked at compile time, no casts needed. |
| **Type erasure** | Generic types are removed after compilation, so `List<String>` and `List<Integer>` are one class at run time. |
| **Bounded type** | `<T extends Number>`: T must be Number or a subtype. |
| **Wildcard** | `?`: an unknown type. `? extends T` reads, `? super T` writes. |
| **PECS** | Producer `extends`, consumer `super`: the rule for choosing a wildcard. |

## Java 8 and after

| Term | In one line |
| --- | --- |
| **Lambda** | A short anonymous function: `s -> s.marks() >= 60`. |
| **Functional interface** | An interface with exactly one abstract method, so a lambda can implement it. |
| **`Predicate` / `Function` / `Consumer` / `Supplier`** | Test to boolean / transform / take and return nothing / take nothing and return. |
| **Effectively final** | A local variable never reassigned. The only kind a lambda may use. |
| **Method reference** | `Student::name`: a lambda that only calls one existing method. |
| **Stream** | A pipeline of operations over a sequence of elements. Not a data store; used once. |
| **Intermediate operation** | Returns a stream and is lazy: `filter`, `map`, `sorted`, `distinct`, `limit`. |
| **Terminal operation** | Produces a result and runs the pipeline: `collect`, `count`, `reduce`, `forEach`. |
| **Lazy evaluation** | Nothing runs until a terminal operation asks for it. |
| **`reduce`** | Combines all elements into one value. |
| **`Collectors.groupingBy`** | Builds a map from a key to the elements with that key. |
| **`partitioningBy`** | Splits into a `Map<Boolean, List<T>>`. |
| **`flatMap`** | Maps each element to a stream and joins them into one. |
| **`Optional`** | A container that may or may not hold a value. Meant for return types. |
| **`java.time`** | The immutable date-time API: `LocalDate`, `LocalDateTime`, `ZonedDateTime`, `Period`, `Duration`. |

## Multithreading

| Term | In one line |
| --- | --- |
| **Process / thread** | A running program with its own memory / a path of execution inside it, sharing the heap. |
| **`Thread` / `Runnable`** | A thread object / a task to run. Prefer passing a `Runnable`. |
| **`start()` vs `run()`** | `start` creates a new thread that calls `run`; calling `run` directly runs it on the current thread. |
| **Thread states** | NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING, TERMINATED. |
| **`join()`** | Wait for another thread to finish. |
| **Race condition** | Two threads changing shared data at once, giving a wrong result that varies by run. |
| **`synchronized`** | Only one thread at a time may run this block for a given lock object. |
| **Intrinsic lock / monitor** | The lock every Java object has, used by `synchronized`. |
| **`volatile`** | Every read sees the latest write. Visibility, not atomicity. |
| **Atomic classes** | `AtomicInteger` and friends: thread-safe updates without `synchronized`. |
| **Deadlock** | Two threads each holding a lock the other needs, waiting for ever. |
| **`ExecutorService`** | A thread pool you submit tasks to instead of creating threads yourself. |
| **`Callable` / `Future`** | A task that returns a value / a handle to its eventual result. |
| **`ConcurrentHashMap`** | A thread-safe map that allows concurrent reads and writes without one global lock. |
| **`CopyOnWriteArrayList`** | A thread-safe list that copies itself on every write. For read-mostly data. |

## Files, JVM, JDBC and tests

| Term | In one line |
| --- | --- |
| **`Path` / `Files`** | A file location / the static methods that read, write and inspect files. |
| **`BufferedReader`** | Reads text in large blocks; `readLine()` returns `null` at the end of the file. |
| **Serialisation** | Turning an object into bytes to save or send. The class implements `Serializable`. |
| **`transient`** | A field skipped by serialisation. |
| **Young / old generation** | Heap areas for new objects / objects that survived several collections. |
| **Metaspace** | Native memory holding class metadata. Replaced PermGen in Java 8. |
| **Garbage collection** | Freeing objects that cannot be reached from any GC root. |
| **GC roots** | Starting points for reachability: live local variables, static fields, active threads. |
| **Memory leak (Java)** | Objects you no longer need but still reference, often from a static collection. |
| **`StackOverflowError`** | A thread's stack is full, usually runaway recursion. |
| **`OutOfMemoryError`** | The heap (or another area) is full of reachable objects. |
| **`-Xmx` / `-Xss`** | Maximum heap size / thread stack size. |
| **Class loader** | Loads `.class` bytes: bootstrap, platform, application. |
| **Parent delegation** | A class loader asks its parent first, so core classes cannot be replaced. |
| **JDBC** | The standard Java API for talking to relational databases. |
| **Driver** | The database vendor's jar that implements JDBC for that database. |
| **`Connection` / `ResultSet`** | A session with the database / the rows a query returned, read with `next()`. |
| **`PreparedStatement`** | Precompiled SQL with `?` placeholders. Prevents SQL injection. |
| **SQL injection** | User input changing the meaning of SQL because it was concatenated into it. |
| **Transaction** | Several statements that commit together or roll back together. |
| **Auto-commit** | JDBC's default: every statement is permanent immediately. |
| **Connection pool** | Reusable open connections, because opening one is slow. HikariCP. |
| **JUnit** | The Java unit testing library. JUnit 5 is also called Jupiter. |
| **Unit test** | Checks one method in isolation, in milliseconds, with no database or network. |
| **Assertion** | A check in a test: `assertEquals(expected, actual)`. |
| **Arrange, act, assert** | Set up, call once, check. |
| **Boundary test** | A test at the value where the rule changes: exactly 75%. |
| **Integration test** | Checks that several pieces work together, for example with a real database. |

## The pairs that get confused

These are the ones an interviewer puts side by side to see whether you know the
difference or only the words.

::accordion
  :::accordion-item{label="JDK against JRE against JVM" icon="i-lucide-git-compare"}
  The JDK contains the JRE, which contains the JVM. You develop with the JDK,
  run with the JRE, and the JVM is the part that executes bytecode.
  :::
  :::accordion-item{label="== against equals" icon="i-lucide-git-compare"}
  `==` compares references for objects (same object?) and values for
  primitives. `equals` compares contents when the class overrides it.
  :::
  :::accordion-item{label="String against StringBuilder against StringBuffer" icon="i-lucide-git-compare"}
  Immutable / mutable and fast / mutable and synchronised. Build text in a loop
  with `StringBuilder`.
  :::
  :::accordion-item{label="Overloading against overriding" icon="i-lucide-git-compare"}
  Same name, different parameters, chosen at compile time / same signature in a
  subclass, chosen at run time from the actual object.
  :::
  :::accordion-item{label="Abstract class against interface" icon="i-lucide-git-compare"}
  One parent, can hold state and constructors / many per class, no instance
  state, a pure contract (with `default` methods since Java 8).
  :::
  :::accordion-item{label="final against finally against finalize" icon="i-lucide-git-compare"}
  A keyword that stops change / a block that always runs after try / a
  deprecated method the garbage collector might call. Three unrelated things
  with similar names, which is exactly why it is asked.
  :::
  :::accordion-item{label="throw against throws" icon="i-lucide-git-compare"}
  `throw` throws one exception object now / `throws` in a method signature
  declares what it may throw.
  :::
  :::accordion-item{label="Checked against unchecked exceptions" icon="i-lucide-git-compare"}
  The compiler forces handling / it does not. Checked for failures the caller
  can act on, unchecked for bugs.
  :::
  :::accordion-item{label="ArrayList against LinkedList" icon="i-lucide-git-compare"}
  A growable array, fast by index / a chain of nodes, fast at the ends. Choose
  `ArrayList` unless you have measured otherwise.
  :::
  :::accordion-item{label="HashMap against Hashtable against ConcurrentHashMap" icon="i-lucide-git-compare"}
  Not thread-safe, allows one null key / legacy, one lock for everything, no
  nulls / thread-safe with fine-grained locking, no nulls.
  :::
  :::accordion-item{label="HashSet against TreeSet against LinkedHashSet" icon="i-lucide-git-compare"}
  No order / sorted order / insertion order.
  :::
  :::accordion-item{label="Comparable against Comparator" icon="i-lucide-git-compare"}
  One natural order inside the class (`compareTo`) / any number of orders
  outside it (`compare`).
  :::
  :::accordion-item{label="Collection against Collections" icon="i-lucide-git-compare"}
  The root interface / a utility class full of static methods.
  :::
  :::accordion-item{label="map against flatMap" icon="i-lucide-git-compare"}
  One element to one element / one element to a stream of elements, flattened.
  :::
  :::accordion-item{label="start against run" icon="i-lucide-git-compare"}
  A new thread / a plain method call on the current thread.
  :::
  :::accordion-item{label="synchronized against volatile" icon="i-lucide-git-compare"}
  Mutual exclusion and visibility / visibility only. `count++` on a volatile is
  still unsafe.
  :::
  :::accordion-item{label="Statement against PreparedStatement" icon="i-lucide-git-compare"}
  SQL text built as a string, open to injection / precompiled SQL with `?`
  placeholders, safe and reusable.
  :::
  :::accordion-item{label="StackOverflowError against OutOfMemoryError" icon="i-lucide-git-compare"}
  One thread's stack is full / the shared heap is full.
  :::
::
