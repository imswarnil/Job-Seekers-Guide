Calendars were counting days. Logarithms are counting something else: how many
times you multiply a number by itself to reach another. That sentence is the
whole idea.

## Why it matters

Logarithms are a basics-only topic in the written round. They appear in some
TCS NQT, Capgemini and AMCAT-style papers, and in the tougher tracks of service
companies, roughly one question when present. Check the current pattern. You
will not be asked calculus. You will be asked to apply the rules below once or
twice, and the question takes 30 seconds if you know them.

## What it is

```text
log_a(x) = n   means   a^n = x
log_2(8)  = 3  because 2³ = 8
log_10(1000) = 3 because 10³ = 1000
```

`a` is the **base**. When no base is written in an aptitude paper, it is 10.

## What to study

| # | Sub-type | Priority |
| --- | --- | --- |
| 1 | Evaluate a simple log (`log_2 64`) | High |
| 2 | Combine logs with the rules (`log 25 + log 4`) | High |
| 3 | Given `log 2` and `log 3`, find `log 12` or `log 5` | Medium |
| 4 | Solve for the base or the number (`log_x 81 = 4`) | Medium |
| 5 | Number of digits in a large power | Medium |

## The rules

```text
1. log(m × n)   = log m + log n
2. log(m ÷ n)   = log m − log n
3. log(m^k)     = k × log m
4. log_a(a) = 1,   log_a(1) = 0
5. log_a(b)     = log b ÷ log a            (change of base)
6. log_a(b) × log_b(a) = 1

Worth memorising:
  log 2 ≈ 0.3010
  log 3 ≈ 0.4771
  log 5 = 1 − log 2 ≈ 0.6990

Number of digits in N = (integer part of log N) + 1
```

::warning{icon="i-lucide-alert-triangle"}
There is no rule for `log(m + n)`. It is not `log m + log n`. That wrong
version is always one of the options.
::

## A worked example

::accordion
  :::accordion-item{label="Combining with the rules" icon="i-lucide-sigma"}
  **Given log 2 = 0.3010 and log 3 = 0.4771, find log 12.**

  ```text
  12 = 2² × 3
  log 12 = 2 log 2 + log 3 = 0.6020 + 0.4771 = 1.0791
  ```

  **Answer: 1.0791.**
  :::
  :::accordion-item{label="How many digits?" icon="i-lucide-hash"}
  **How many digits does 2^50 have? (log 2 = 0.3010)**

  ```text
  log(2^50) = 50 × 0.3010 = 15.05
  Integer part 15, so digits = 15 + 1 = 16
  ```

  **Answer: 16 digits.** (2^50 is 1,125,899,906,842,624.)
  :::
  :::accordion-item{label="Solve for the base" icon="i-lucide-variable"}
  **If log_x 81 = 4, find x.**

  ```text
  x⁴ = 81 = 3⁴  →  x = 3
  ```
  :::
::

## Common mistakes

- **Inventing a rule for sums.** `log(a + b)` does not split.
- **Forgetting the base is 10** when none is written.
- **Adding 1 twice** in digit questions, or forgetting it.
- **Losing the minus sign** with fractions: `log_2(1/8) = −3`.

## Practice questions

::accordion
  :::accordion-item{label="1. log_3 243?"}
  **5.** `3⁵ = 243`.
  :::
  :::accordion-item{label="2. log 5, given log 2 = 0.3010?"}
  **0.6990.** `log 5 = log 10 − log 2`.
  :::
  :::accordion-item{label="3. log_2 8 × log_8 2?"}
  **1.** Rule 6.
  :::
  :::accordion-item{label="4. log_x (1/16) = −2. Find x."}
  **4.** `x^(−2) = 1/16`, so `x² = 16`.
  :::
  :::accordion-item{label="5. How many digits in 3^20? (log 3 = 0.4771)"}
  **10.** `20 × 0.4771 = 9.542`; `9 + 1 = 10`.
  :::
  :::accordion-item{label="6. log 25 + log 4?"}
  **2.** `log 100`.
  :::
