Before the reading chapter, the words from this one. Only the new ones, one line
each.

## The sections you will meet

| Term | What it is |
| --- | --- |
| **Written round** | The first filter in a campus drive. Usually aptitude, reasoning and English, on a computer, against a clock. Not an interview. |
| **Online assessment (OA)** | The same thing for off-campus applications, sent as a link. Often includes one or two coding questions as well. |
| **Quantitative aptitude** | Arithmetic, percentages, ratios, time and work, probability. Speed matters far more than depth. |
| **Logical reasoning** | Series, seating arrangements, syllogisms, blood relations. Pattern recognition under time pressure. |
| **Verbal ability** | The English section: comprehension, grammar, vocabulary, sentence ordering. What this chapter is about. |
| **Cut-off** | The score below which you are removed. Usually not published, and usually sectional as well as overall. |
| **Sectional cut-off** | A minimum in *each* section. This is why being excellent at aptitude does not rescue a weak English score. |
| **Negative marking** | Marks deducted for wrong answers. Changes the guessing strategy completely, with it, only guess after eliminating two options. |

## The English terms used in this chapter

| Term | In one line |
| --- | --- |
| **Comprehension** | Finding specific information in a passage you have not seen before. |
| **Inference question** | A question whose answer is not stated in the passage but follows from it. |
| **Locate-a-fact question** | A question whose answer is a phrase sitting in the passage. Free marks. |
| **Subject-verb agreement** | A singular subject takes a singular verb, however many words sit between them. |
| **Modifier** | A phrase that describes something. It attaches to whatever noun is next to it, whether you meant it to or not. |
| **Dangling modifier** | A modifier whose intended owner is not in the sentence. *"Having failed the exam, the registrar rejected it."* |
| **Parallelism** | Items in a list sharing the same grammatical shape. |
| **Antecedent** | The noun a pronoun refers back to. If two nouns could be it, the sentence is broken. |
| **Register** | How formal the language is. A formal passage will not take a casual word, which is how you eliminate an option. |
| **Root, prefix, suffix** | The parts a word is built from. `in-` + `trans-` + root = intransigent. |
| **Connective** | However, therefore, this, so, it. The words that chain sentences together, and the whole method for ordering them. |

## The one distinction worth memorising

::pull-quote
Fluency is how you sound. Clarity is whether the reader knows what to do next.
Interviews and written rounds mark the second one, and almost everybody prepares
for the first.
::
