Six rules. I am not going to teach you English grammar, because you already speak
this language and because the round does not test English grammar. It tests six
recurring patterns, and once you can see them the section takes four minutes
instead of fifteen.

## Why this matters in a job

Two reasons, and the second one lasts longer.

The round is the obvious one. The lasting one is that four of these six errors
change what a sentence *means*, which means they change what somebody does. A
misplaced modifier in a bug report sends a developer to the wrong file.

## Rule one: subject and verb must agree, past whatever is in between

The test always separates them with a phrase, because that is what makes it hard.

::compare{caption="Find the subject. Ignore everything between it and the verb."}
  :::compare-side{label="Wrong" verdict="wrong"}
  *The list of shortlisted applicants **were** published on Friday.*

  The subject is `list`, which is singular. `of shortlisted applicants` is a
  phrase hanging off it, and the verb has been made to agree with the nearest
  noun instead of the actual subject.
  :::
  :::compare-side{label="Right" verdict="right"}
  *The list of shortlisted applicants **was** published on Friday.*

  Strike out the middle phrase and read it: "the list was published". Obvious.
  :::
::

**The technique:** cross out everything between the subject and the verb, then
read what is left. That is the entire rule.

## Rule two: a modifier attaches to whatever it is next to

This one is genuinely funny once you can see it, and it is the one that causes
real confusion in writing.

::compare{caption="The opening phrase describes whatever noun comes next. Whatever noun comes next."}
  :::compare-side{label="Wrong" verdict="wrong"}
  *Having failed the qualifying examination, the registrar rejected the
  application.*

  As written, the registrar failed the examination.
  :::
  :::compare-side{label="Right" verdict="right"}
  *Because the applicant had failed the qualifying examination, the registrar
  rejected the application.*

  Or: *Having failed the qualifying examination, the applicant was rejected.*
  :::
::

## Rule three: things in a list must have the same shape

::compare{caption="Parallelism. Read the list items as if each one followed the stem on its own."}
  :::compare-side{label="Wrong" verdict="wrong"}
  *The registrar is responsible for shortlisting applicants, fee collection, and
  to publish the results.*

  Three different shapes: an -ing, a noun, and an infinitive.
  :::
  :::compare-side{label="Right" verdict="right"}
  *The registrar is responsible for shortlisting applicants, collecting fees, and
  publishing the results.*
  :::
::

## Rule four: the pronoun must have exactly one possible owner

::compare{caption="If two nouns could own the pronoun, the sentence is broken even though everybody can guess."}
  :::compare-side{label="Wrong" verdict="wrong"}
  *The dean told the registrar that **his** decision would be reviewed.*

  Whose decision?
  :::
  :::compare-side{label="Right" verdict="right"}
  *The dean told the registrar that the registrar's decision would be reviewed.*

  Clumsy and unambiguous. Unambiguous wins, in a test and in a bug report.
  :::
::

## Rule five: tense should not move without a reason

::compare{caption="Pick a time and stay in it."}
  :::compare-side{label="Wrong" verdict="wrong"}
  *The applicant submitted the form and then **asks** for a receipt.*
  :::
  :::compare-side{label="Right" verdict="right"}
  *The applicant submitted the form and then **asked** for a receipt.*
  :::
::

## Rule six: the twelve confused pairs

These are the same twelve every time. Learn these and you have the vocabulary
section of most papers.

| Pair | The distinction, in one line |
| --- | --- |
| affect / effect | Affect is usually the verb, effect usually the noun. *The delay affected the results. The effect was a backlog.* |
| its / it's | `it's` is only ever "it is". If you cannot expand it, use `its`. |
| their / there / they're | Belonging / place / they are. |
| fewer / less | Fewer applicants. Less time. Countable takes fewer. |
| between / among | Between two. Among more than two. |
| principal / principle | The principal runs the college. A principle is a rule. |
| accept / except | Accept the offer. Everyone except him. |
| advice / advise | Advice is the noun. Advise is the verb. |
| complement / compliment | Complement completes. Compliment praises. |
| ensure / insure | Ensure it happens. Insure against loss. |
| lose / loose | Lose the file. A loose connection. |
| then / than | Then is time. Than is comparison. |

::real-life{title="Where rule two costs you money" source="A bug report I actually received"}
*"After clicking submit, the server returns a 500 error and the page reloads,
losing the data."* Fine. But: *"Having timed out, the developer restarted the
service."* Who timed out? I spent twenty minutes looking at the developer's
machine because the sentence said the developer timed out. Grammar is not
etiquette here. It is routing.
::

## What confuses people here

That you need to learn grammar terminology. You do not. Not one of the six above
requires you to be able to name a gerund. The test is multiple choice, and every
one of these is solved by reading the options aloud and applying a one-line
technique.

## Your turn

Fix these six. One rule each, in order.

1. *The set of attendance records for all first-year students are missing.*
2. *Running the fee report, an error appeared on the screen.*
3. *The system handles admissions, fee payment, and it tracks attendance.*
4. *The tester told the developer that his code was unclear.*
5. *She opened the file, read the total and then closes it.*
6. *The new policy will effect fewer students then the old one.*

::accordion
  :::accordion-item{label="Answers" icon="i-lucide-check"}
  1. *The **set** of attendance records for all first-year students **is**
     missing.* Cross out "of attendance records for all first-year students".
  2. *While running the fee report, **I** saw an error on the screen.* The error
     was not running the report.
  3. *The system handles admissions, fee payment and attendance tracking.* Three
     nouns.
  4. *The tester told the developer that the developer's code was unclear.*
     Clumsy, unambiguous, correct.
  5. *She opened the file, read the total and then **closed** it.*
  6. *The new policy will **affect** fewer students **than** the old one.* Two
     errors in one short sentence, which is exactly how the test writes them.
  :::
::

## Check yourself

1. What is the one-line technique for subject-verb agreement, and why does the
   test always insert a phrase in the middle?
2. **Rewrite this so it says what it means:** *"Being incomplete, the registrar
   returned the application."*

## The interview question this answers

Again, none directly. What this lesson buys you is that nothing you write will
ever be the reason somebody quietly downgrades their opinion of you, and in a
written round it is roughly ten marks that most candidates leave on the table.
