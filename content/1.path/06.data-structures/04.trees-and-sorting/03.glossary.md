## The cost table

| Structure | Access by index | Search by value | Insert | Delete | Notes |
| --- | --- | --- | --- | --- | --- |
| Array / `ArrayList` | **O(1)** | O(n) | O(1) at end, O(n) middle | O(n) | Contiguous, so cache-friendly. The default. |
| Linked list | O(n) | O(n) | O(1) **if already there** | O(1) if already there | ~2× memory. Rarely the right answer. |
| `ArrayDeque` | O(1) | O(n) | **O(1) both ends** | **O(1) both ends** | The real stack and queue in Java |
| Stack | top only | O(n) | O(1) | O(1) | Last in, first out |
| Queue | ends only | O(n) | O(1) | O(1) | First in, first out |
| `PriorityQueue` (heap) | top only | O(n) | O(log n) | O(log n) | Highest priority out first |
| `HashMap` / `HashSet` | by key **O(1)** avg | O(1) avg | O(1) avg | O(1) avg | No order. O(n) worst case with a bad hash. |
| `TreeMap` / `TreeSet` | by key O(log n) | O(log n) | O(log n) | O(log n) | **Sorted**, and supports ranges |
| Binary search tree | O(log n) balanced | O(log n) | O(log n) | O(log n) | **O(n) if unbalanced** |

## Complexity

| Term | In one line |
| --- | --- |
| **O(1)** | Constant. Ten times the input, the same work. |
| **O(log n)** | Logarithmic. A thousand times the input, ten more steps. |
| **O(n)** | Linear. Ten times the input, ten times the work. |
| **O(n log n)** | The best a general comparison sort can do. |
| **O(n²)** | Quadratic. Ten times the input, a hundred times the work. |
| **Amortised** | Averaged across many operations. `ArrayList.add` is amortised O(1): usually cheap, occasionally a full copy. |
| **Best / worst / average** | An unqualified complexity means the **worst** case, which is what happens on results day. |
| **Space complexity** | The same notation applied to memory. Merge sort is O(n) space; quicksort is O(log n). |

## Structures

| Term | In one line |
| --- | --- |
| **Contiguous** | Stored next to each other in memory. Why arrays are fast twice over: O(1) access and no cache misses. |
| **Cache miss** | Reading memory that is not in the processor's fast cache. Roughly a hundred times slower, and what makes linked lists slow in practice. |
| **Node** | One element of a linked structure: a value plus one or more pointers. |
| **Head / tail** | The first and last nodes of a linked list. |
| **Deque** | Double-ended queue. Add and remove at both ends, so it is both a stack and a queue. |
| **Heap** | A tree where every parent outranks its children, stored in an array. What a priority queue is. Nothing to do with the JVM heap. |
| **Hash function** | Turns a key into a number. A good one spreads keys evenly across buckets. |
| **Bucket** | One slot of a hash table. Several keys can land in one. |
| **Collision** | Two keys in the same bucket. Normal and expected, handled with a list or a tree inside the bucket. |
| **Load factor** | Entries ÷ buckets. Java resizes at 0.75, and resizing rehashes **everything**. |
| **equals / hashCode contract** | Equal objects **must** have equal hash codes. Break it and a map cannot find an entry sitting inside it. |
| **Balanced tree** | One kept shallow as items are inserted. Red-black in `TreeMap`, B-tree in a database index. |
| **In-order traversal** | Left, self, right. On a search tree this yields sorted output. |
| **Level-order / BFS** | Row by row, using a **queue**. Shortest path in an unweighted graph. |
| **Depth-first / DFS** | Down one branch first, using a **stack** — or recursion, which is the call stack. |
| **Stable sort** | Equal elements keep their original relative order. What makes a shortlist reproducible. |
| **Timsort** | Java's sort for objects. Merge sort that exploits runs already in order. Stable, O(n log n). |
| **Pivot** | The element quicksort partitions around. A bad pivot is what makes it O(n²). |

## The five sentences to keep

::pull-quote
Big-O answers one question: ten times the input, how much more work. An array is
fast because it is contiguous. A hash table is O(1) until your hash is bad.
A search tree is O(log n) until it is unbalanced. And a stable sort is what makes
a shortlist you can explain to a parent.
::
