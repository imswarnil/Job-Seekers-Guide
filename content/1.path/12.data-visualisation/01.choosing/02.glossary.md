One chapter, in one page.

| Term | In one line |
| --- | --- |
| **Encoding** | What carries the meaning: length in a bar, position in a scatter, angle in a pie. Humans read length well and angle badly. |
| **Baseline** | Where the axis starts. A **bar** must start at zero because its length is the encoding; a **line** need not, because its slope is. |
| **Truncated axis** | An axis starting above zero. Makes 412 → 460 look like explosive growth. The most common way a true chart lies. |
| **Categorical** | Distinct groups: programmes, statuses. Compare with a bar chart, sorted by value. |
| **Continuous** | A measure: score, fee, date. Distribute with a histogram, relate with a scatter. |
| **Time series** | Change over time. Time on the horizontal, always, and a line rather than bars. |
| **Histogram** | Distribution of one measure, in bands. Not a bar chart: the bands are ranges, so there are no gaps. |
| **Bin width** | The band size in a histogram. Choosing it changes the picture, so it is a decision to disclose. |
| **Stacked bar** | Only the bottom segment starts at zero, so only it can be compared across bars. Fine for a total, misleading for parts. |
| **Dual axis** | Two scales on one chart. The crossing point is an artefact of the scales, so it implies a relationship you invented. |
| **Legend** | A lookup table you are asking the reader to memorise. Label directly where you can. |
| **Small multiples** | The same chart repeated per category, on one scale. Usually better than one chart with six colours. |
| **Colour-blind safe** | Colour is never the only signal. About one man in twelve cannot separate red from green. |
| **Caption** | Where you say what the query excluded. Every chart is a query; every query excluded something. |

## The three sentences to keep

::pull-quote
The question decides the shape. A bar chart starts at zero. And the caption is
what turns a picture into a claim somebody can check.
::
