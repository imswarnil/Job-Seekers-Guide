Two chapters of CSS, in one page.

## Why it is not applying

| Term | In one line |
| --- | --- |
| **Cascade** | The order rules are resolved in: importance, then specificity, then source order. |
| **Specificity** | Counted as ids, classes, elements, compared **left to right**. One id beats any number of classes. |
| **Inheritance** | Text properties pass to children; box properties do not. A form control inherits almost nothing unless asked. |
| **`!important`** | Wins now, and can then only be beaten by another. A deferral, not a fix. |
| **Box model** | Content, padding, border, margin, outward. |
| **`box-sizing: border-box`** | Makes `width` mean the whole box. Set it globally in the first three lines of every stylesheet. |
| **Margin collapse** | Adjacent vertical margins become the larger one, not the sum. Does not happen in flex or grid. |
| **Specificity 0,1,0** | A class. `0,0,1` an element, `1,0,0` an id. The notation an interviewer will use. |

## Layout

| Term | In one line |
| --- | --- |
| **Flexbox** | One dimension. A row or a column, where the content decides the sizes. |
| **Grid** | Two dimensions. You define rows and columns in advance. |
| **Main axis** | What `justify-content` works on. Horizontal in a row, vertical in a column. |
| **Cross axis** | What `align-items` works on. The other one. Both swap when `flex-direction` changes, which is the whole source of the confusion. |
| **`gap`** | Space between items. Replaced most of the margin arithmetic layout used to be made of, and does not collapse. |
| **`fr`** | A fraction of the remaining space, in grid. `1fr 2fr` is a third and two thirds. |
| **`minmax(18rem, 1fr)`** | At least this, then share what is left. With `auto-fill`, a responsive grid with no media queries. |
| **`auto-fill` / `auto-fit`** | As many columns as fit. `auto-fit` collapses the empty ones, which changes how a part-full row looks. |
| **Media query** | A breakpoint. Needed far less than it used to be, because of the line above. |
| **`position: sticky`** | Scrolls until it hits an offset, then stops. Only travels **inside its containing block**, which is why a sticky element in a short parent appears not to work. |

## Units, and the ones worth using

| Unit | Use it for |
| --- | --- |
| `rem` | Almost everything. Relative to the root, so it respects a user's font size. |
| `em` | Spacing that should scale with *this* element's text, such as padding inside a button. |
| `px` | Borders, and hairlines. |
| `%` | Widths inside a sized parent. |
| `ch` | Reading measure. `max-width: 65ch` is roughly the right line length, in any font. |
| `dvh` | Full-height on a phone, where `vh` is cropped by the collapsing URL bar. |
| `clamp(min, ideal, max)` | Type that scales with the viewport and cannot get silly at either end. |

## The four sentences to keep

::pull-quote
Specificity is compared left to right, so one id outranks a hundred classes. Set
`border-box` globally. Flex is one dimension and grid is two. And a sticky
element can only travel inside its parent's box.
::
