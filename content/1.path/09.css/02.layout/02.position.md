Normal flow puts boxes one after another. `position` is how an element steps out
of that line, and the whole property comes down to one question for each value:
positioned relative to *what*?

## Why this matters in a job

Because "relative against absolute" is a standard interview question, and
because the answer most people give ("absolute is positioned relative to the
page") is wrong in the case that matters. At work, `position` builds every badge
in a corner, every dropdown, every modal and every sticky table header.

## Five values, five reference points

Think of exam hall seating. `static` is sitting in your allotted seat. `relative`
is leaning a little from your seat while your seat stays reserved. `absolute` is
standing up and placing yourself relative to the nearest invigilator's desk,
leaving your seat free for others. `fixed` is being pinned to the hall's wall
whatever happens. `sticky` is sitting normally until the rows scroll past, then
holding on at the top.

| Value | In normal flow? | `top`/`left` are measured from |
| --- | --- | --- |
| `static` (default) | Yes | Ignored |
| `relative` | Yes, space is kept | Where it would have been |
| `absolute` | No, space is removed | The nearest **positioned** ancestor (any value except `static`); if none, the page |
| `fixed` | No | The viewport. Stays put when you scroll |
| `sticky` | Yes, until a threshold | Scrolls normally, then sticks at `top: 0` inside its parent |

## How it works

A student card with a badge pinned to its top-right corner:

```html [card.html]
<article class="student-card">
  <span class="badge">Fees due</span>
  <h3>Imran Khan</h3>
  <p>B.Tech CSE, 3rd year</p>
</article>
```

```css [card.css]
.student-card {
  position: relative;        /* makes the card the reference point */
  width: 260px;
  padding: 1rem;
  border: 1px solid #cbd5e1;
}
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
  background: #fee2e2;
  padding: 2px 6px;
}
```

```text [Output]
The badge sits 8px from the top and 8px from the right edge of the card.
The heading starts at the top of the card: the badge takes up no space in the flow.
Remove position: relative from the card and the badge jumps to the top-right
corner of the whole page.
```

::runner{lang="css"}
```css
.student-card { position: relative; width: 260px; padding: 1rem; border: 1px solid #cbd5e1; }
.badge { position: absolute; top: 8px; right: 8px; background: #fee2e2; padding: 2px 6px; }

/* --- html --- */
<article class="student-card">
  <span class="badge">Fees due</span>
  <h3>Imran Khan</h3>
  <p>B.Tech CSE, 3rd year</p>
</article>
```
::

That pattern, a `relative` parent and an `absolute` child, is the single most
common use of `position`. The parent's `relative` moves nothing. It is there
only to become the reference point.

### z-index and stacking contexts

When positioned elements overlap, `z-index` decides which is on top: a higher
number is closer to you. It only works on positioned elements (and on flex and
grid children).

The catch is the **stacking context**. Some properties, including a `position`
with a `z-index`, `opacity` below 1 and `transform`, make an element a sealed
layer. Its children's `z-index` values only compete with each other inside it.

```css [stacking.css]
.header  { position: relative; z-index: 2; }
.content { position: relative; z-index: 1; }
.content .dropdown { position: absolute; z-index: 9999; }
```

```text [Output]
The dropdown still appears BEHIND the header.
Its 9999 only counts inside .content, and .content as a whole is at 1, below 2.
```

It is like ranks within a department. The top student in ECE cannot outrank the
CSE department as a whole in a list sorted by department first.

## Real use case

A long attendance register where the header row stays visible while you scroll
through 120 students:

```css [register.css]
.register thead th {
  position: sticky;
  top: 0;
  background: white;   /* without it, rows show through the header */
  z-index: 1;
}
```

And a "Back to top" button on a long syllabus page:

```css [back-to-top.css]
.back-to-top { position: fixed; right: 1rem; bottom: 1rem; }
```

## What confuses people here

**Absolute is not relative to the page.** It is relative to the nearest
positioned ancestor, and only falls back to the page when there is none. That is
why the badge jumped when the card lost `position: relative`.

**Sticky "does not work".** It usually does. A sticky element can only travel
inside its parent, so in a short parent it has nowhere to stick. The other
culprit is an ancestor with `overflow: hidden`, which becomes the scroll area it
sticks inside.

**Raising z-index to 9999 does not help** once a stacking context is in the way.
Find the ancestor that created the context and change its `z-index` instead.

## Interview questions

::accordion
  :::accordion-item{label="What is the difference between relative and absolute?" icon="i-lucide-message-circle"}
  `relative` moves an element from where it would normally be and keeps its
  space in the flow. `absolute` removes it from the flow and positions it
  against the nearest ancestor that is positioned (not `static`), or the page
  if there is none.
  :::
  :::accordion-item{label="Fixed against sticky?" icon="i-lucide-message-circle"}
  `fixed` is positioned against the viewport and never scrolls. `sticky`
  behaves like `relative` until it reaches its offset (say `top: 0`), then sticks,
  but only while its parent is on screen.
  :::
  :::accordion-item{label="Why is my z-index not working?" icon="i-lucide-message-circle"}
  Either the element is not positioned (z-index needs `position` other than
  static, or a flex or grid parent), or it is inside a stacking context that is
  itself below the other element. Inspect the ancestors for `z-index`,
  `opacity` or `transform`.
  :::
  :::accordion-item{label="What is the default value of position?" icon="i-lucide-message-circle"}
  `static`. `top`, `left`, `right`, `bottom` and `z-index` have no effect on a
  static element.
  :::
  :::accordion-item{label="How would you place a badge in the corner of a card?" icon="i-lucide-message-circle"}
  `position: relative` on the card, `position: absolute; top: 8px; right: 8px`
  on the badge.
  :::
::
