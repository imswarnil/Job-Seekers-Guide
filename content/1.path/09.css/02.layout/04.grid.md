Grid is Flexbox's partner for two directions. Where Flexbox lets the content
decide the sizes along one line, Grid lets you draw the rows and columns first
and then place things into them, so a timetable's Monday column lines up from
the first period to the last.

## Why this matters in a job

Because every page layout (header, sidebar, main, footer) is a grid, and because
"Flexbox or Grid?" is asked in every front-end interview. The one line in this
lesson that builds a responsive card grid with no media queries is also the line
most likely to impress whoever is reading your code.

## Drawing the timetable first

A department timetable is ruled before anything is written in it: six columns,
eight rows, the lunch break spanning all columns. Grid works exactly like that.
You rule the lines on the container; the children fall into the cells.

- `grid-template-columns` and `grid-template-rows` set the tracks.
- `fr` is a **fraction of the remaining space**: `1fr 2fr` is a third and two
  thirds.
- `repeat(5, 1fr)` is `1fr 1fr 1fr 1fr 1fr`.
- `minmax(12rem, 1fr)` means "at least 12rem, and share what is left".
- `gap` sets the space between rows and columns.
- An item can span tracks with `grid-column: 1 / 3` (from line 1 to line 3) or
  `grid-column: span 2`.

::pull-quote
Flexbox lays things out in **one** direction. Grid lays things out in **two**.
If you are arranging a row or a column, use flex. If you are arranging rows and
columns at once, use grid.
::

## How it works

A weekly timetable for CSE 3rd year:

```html [timetable.html]
<div class="timetable">
  <div></div><div class="day">Mon</div><div class="day">Tue</div><div class="day">Wed</div>
  <div class="time">9:00</div><div>OS</div><div>DBMS</div><div>Networks</div>
  <div class="time">10:00</div><div>DBMS</div><div>OS lab</div><div>Maths</div>
  <div class="lunch">Lunch</div>
  <div class="time">2:00</div><div>Networks</div><div>OS lab</div><div>Library</div>
</div>
```

```css [timetable.css]
.timetable {
  display: grid;
  grid-template-columns: 5rem repeat(3, 1fr);
  gap: 4px;
}
.timetable > div { padding: 0.5rem; background: #f1f5f9; }
.lunch { grid-column: 1 / -1; text-align: center; }   /* first line to last line */
```

```text [Output]
       | Mon      | Tue    | Wed
  9:00 | OS       | DBMS   | Networks
 10:00 | DBMS     | OS lab | Maths
 ------------- Lunch (spans all four columns) -------------
  2:00 | Networks | OS lab | Library
In a 500px container: first column 80px, the other three share
(500 - 80 - 3 × 4px gap) / 3 = 136px each.
```

### Named areas

For a page layout, you can draw it in words:

```css [page.css]
.page {
  display: grid;
  grid-template-columns: 16rem 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
  gap: 1rem;
}
.page > header { grid-area: header; }
.page > nav    { grid-area: sidebar; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }
```

```text [Output]
+---------------- header ----------------+
| sidebar 16rem |  main (the rest)        |
+---------------- footer ----------------+
The footer sits at the bottom of the screen even when main is short,
because the middle row is 1fr of a container at least 100vh tall.
```

## Real use case

The line worth remembering from this track, used for every card gallery (the
faculty directory, the placement drive list, course cards):

```css [faculty.css]
.faculty-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  gap: 1rem;
}
```

It says: as many columns as fit, each at least 16rem, sharing the remaining
space equally. On a phone that is one column, on a laptop three, on a projector
five, and you wrote no breakpoints. `auto-fit` is the same except that when
there are fewer cards than columns, the empty columns collapse and the cards
stretch.

In real codebases the two tools are used together: Grid for the page and for
galleries, Flexbox inside each card and each toolbar.

  :::
  :::compare-side{label="Grid" verdict="neutral"}
  The page itself, a timetable, a gallery of cards that must line up in both
  directions, a form with labels aligned down a column. **You** decide the
  structure.

## What confuses people here

**`1fr` shrinks only so far.** A column of `1fr` will not go narrower than its
longest unbreakable content, such as a long email address, and pushes the grid
wide. Write `minmax(0, 1fr)` when the column must be allowed to shrink.

**Grid lines are numbered from 1**, and there is one more line than there are
columns. Three columns have lines 1 to 4. `-1` is always the last line.

**Only direct children are grid items.** A card inside a grid cell does not
line up with the grid unless it is a direct child (or you use `subgrid`).

## Interview questions

::accordion
  :::accordion-item{label="When would you use Flexbox and when Grid?" icon="i-lucide-message-circle"}
  Flexbox for one dimension, a row or a column where content decides sizes.
  Grid for two dimensions, where you define rows and columns up front. They are
  often combined: Grid for the page, Flexbox inside each region.
  :::
  :::accordion-item{label="What is the fr unit?" icon="i-lucide-message-circle"}
  A fraction of the free space left after fixed tracks and gaps. In
  `200px 1fr 2fr` in an 800px container, the 600px left over is split 200 and
  400.
  :::
  :::accordion-item{label="How do you make a responsive grid without media queries?" icon="i-lucide-message-circle"}
  `grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));`. As many
  columns as fit at a minimum of 16rem, sharing the rest.
  :::
  :::accordion-item{label="auto-fill against auto-fit?" icon="i-lucide-message-circle"}
  Both create as many tracks as fit. With few items, `auto-fill` keeps the
  empty tracks so items stay their minimum width, while `auto-fit` collapses
  empty tracks so items stretch to fill the row.
  :::
  :::accordion-item{label="How do you make an item span two columns?" icon="i-lucide-message-circle"}
  `grid-column: span 2;` or with explicit lines, `grid-column: 1 / 3;`. To span
  every column, `grid-column: 1 / -1;`.
  :::
::
