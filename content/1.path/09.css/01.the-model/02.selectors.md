A selector is the part of a rule before the braces, and it answers one question:
which elements does this apply to? Tag names and classes will get you started.
The rest of the selector language exists so you do not have to add a class to
every element you want to reach.

## Why this matters in a job

Because the selector decides both *what* gets styled and *how hard it is to
override later*. Picking the right one keeps a stylesheet short. In interviews,
freshers are asked to explain the difference between `div p` and `div > p`, or
between `:hover` and `::before`, and the second one trips most people up.

## The selector, as a way of pointing

Imagine standing at the front of a lecture hall and asking some people to stand
up. "Everyone" is one instruction. "Everyone in the CSE batch" is another.
"Roll number 42" is a third. "Everyone sitting directly behind a topper" is a
fourth. Selectors are the same set of ways to point, written in code.

::compare{caption="The basic selectors."}
  :::compare-side{label="Simple selectors" verdict="neutral"}
  `*` everything · `p` every paragraph (a **type** selector) · `.topper` every
  element with that class · `#result-42` the one element with that id ·
  `[required]` every element with that attribute · `[type="email"]` with that
  attribute value.
  :::
  :::compare-side{label="Combinators" verdict="neutral"}
  `table td` a `td` anywhere inside a table (**descendant**) · `ul > li` an `li`
  directly inside a `ul` (**child**) · `h2 + p` the paragraph immediately after
  an `h2` (**adjacent sibling**) · `h2 ~ p` every later paragraph with the same
  parent (**general sibling**).
  :::
::

Two more families finish the language:

- A **pseudo-class** selects an element in a particular *state or position*. It
  has one colon: `:hover`, `:focus`, `:checked`, `:disabled`, `:first-child`,
  `:nth-child(2n)`, `:not(.passed)`.
- A **pseudo-element** styles a *part* of an element, or adds a box that is not
  in the HTML. It has two colons: `::before`, `::after`, `::first-line`,
  `::placeholder`, `::marker`.

Selectors can be grouped with a comma: `h1, h2, h3 { font-family: Georgia; }`
is three rules written once.

## How it works

A semester results table. Not one class is needed to stripe it, highlight the
row under the mouse and mark failing scores.

```html [results.html]
<table class="results">
  <caption>Semester 5 results, CSE</caption>
  <thead>
    <tr><th>Student</th><th>Subject</th><th>Score</th></tr>
  </thead>
  <tbody>
    <tr><td>Asha Rao</td><td>Operating Systems</td><td data-status="pass">78</td></tr>
    <tr><td>Imran Khan</td><td>Operating Systems</td><td data-status="fail">31</td></tr>
    <tr><td>Neha Joshi</td><td>Operating Systems</td><td data-status="pass">64</td></tr>
    <tr><td>Ravi Kumar</td><td>Operating Systems</td><td data-status="pass">55</td></tr>
  </tbody>
</table>
```

```css [results.css]
.results { border-collapse: collapse; }
.results th, .results td { padding: 0.5rem 1rem; text-align: left; }

/* child combinator: only rows directly inside tbody */
.results tbody > tr:nth-child(even) { background: #f3f4f6; }

/* pseudo-class: the row under the pointer */
.results tbody tr:hover { background: #e0f2fe; }

/* attribute selector: no extra class needed */
.results td[data-status="fail"] { color: #b91c1c; font-weight: 600; }

/* pseudo-element: add text that is not in the HTML */
.results td[data-status="fail"]::after { content: " (re-appear)"; font-weight: 400; }
```

```text [Output]
Asha Rao    Operating Systems   78
Imran Khan  Operating Systems   31 (re-appear)   <- red, bold score
Neha Joshi  Operating Systems   64
Ravi Kumar  Operating Systems   55
Rows 2 and 4 have a grey background. The row under the mouse turns light blue.
```

### How `:nth-child` counts

`:nth-child(an+b)` picks every element whose position (counting from 1) fits the
formula for some n = 0, 1, 2 and so on.

| Selector | Picks positions |
| --- | --- |
| `:nth-child(3)` | 3 only |
| `:nth-child(odd)` or `(2n+1)` | 1, 3, 5, 7 … |
| `:nth-child(even)` or `(2n)` | 2, 4, 6 … |
| `:nth-child(3n)` | 3, 6, 9 … |
| `:nth-child(-n+3)` | 1, 2, 3 (the first three) |

It counts **all** siblings, whatever their type. `p:nth-child(2)` means "the
second child, if it happens to be a `p`", not "the second paragraph". For the
second paragraph use `p:nth-of-type(2)`.

## Real use case

Form styling is where these pay for themselves. An admissions enquiry form can
show its states without JavaScript touching a class:

```css [enquiry-form.css]
input:focus-visible { outline: 3px solid #2563eb; outline-offset: 2px; }
input[required] + .hint::before { content: "Required. "; font-weight: 600; }
input:invalid:not(:placeholder-shown) { border-color: #b91c1c; }
button:disabled { opacity: 0.5; cursor: not-allowed; }
label:has(input:checked) { background: #ecfdf5; }
```

The last line uses `:has()`, a pseudo-class that selects a parent by what it
contains. It works in every current browser and is worth knowing exists: it is
the first time CSS could select "the label that contains a ticked checkbox".

## What confuses people here

**One colon or two.** `:hover` is a state of an existing element. `::before` is
a new box the browser inserts as the first child. A `::before` or `::after`
shows nothing unless it has a `content` property, even `content: ""`.

**Descendant against child.** `.results td` reaches every `td` at any depth,
including cells in a table nested inside a cell. `.results > td` reaches none,
because a `td` is never a direct child of a `table`. When a child combinator
matches nothing, check the real HTML structure in developer tools, including the
`<tbody>` the browser adds even if you did not write one.

**A space changes everything.** `.card.featured` (no space) is one element with
both classes. `.card .featured` (a space) is a `.featured` element inside a
`.card`.

## Interview questions

::accordion
  :::accordion-item{label="What is the difference between div p and div > p?" icon="i-lucide-message-circle"}
  `div p` is the descendant combinator: any `p` inside a `div`, at any depth.
  `div > p` is the child combinator: only a `p` whose direct parent is the `div`.

  ```html
  <div><p>matched by both</p><section><p>only by div p</p></section></div>
  ```
  :::
  :::accordion-item{label="Pseudo-class against pseudo-element?" icon="i-lucide-message-circle"}
  A pseudo-class (one colon) selects an existing element in a state or position:
  `:hover`, `:focus`, `:nth-child(2)`. A pseudo-element (two colons) styles a
  part of an element or creates a new box: `::before`, `::after`,
  `::first-line`. `::before` needs `content` to appear.
  :::
  :::accordion-item{label="What does + do, and how is it different from ~?" icon="i-lucide-message-circle"}
  `h2 + p` selects the one paragraph immediately after an `h2`. `h2 ~ p` selects
  every paragraph after the `h2` that shares its parent. Both only look forward,
  never backward.
  :::
  :::accordion-item{label="How would you select every third row of a table?" icon="i-lucide-message-circle"}
  `tr:nth-child(3n)`, which matches positions 3, 6, 9. The first three rows would
  be `tr:nth-child(-n+3)`.
  :::
  :::accordion-item{label="What is the universal selector and when is it used?" icon="i-lucide-message-circle"}
  `*` matches every element. Its most common real use is the reset
  `*, *::before, *::after { box-sizing: border-box; }`, which you will meet in
  the box model lesson.
  :::
::
