## Real use case

This is the vocabulary of a front-end code review. When a senior writes "this
bumps specificity, use a single class" or "border-box is already set globally",
every term in that sentence is on this page.

### Applying style

| Term | In one line |
| --- | --- |
| **Rule** | A selector plus a block of declarations: `.note { color: red; }`. |
| **Declaration** | One property and value: `color: red`. |
| **External stylesheet** | A `.css` file attached with `<link rel="stylesheet">`. Cached, shared by every page. |
| **Internal stylesheet** | A `<style>` block in the page's head. |
| **Inline style** | A `style` attribute on one element. Beats every normal stylesheet rule. |
| **`@import`** | Pulls one stylesheet into another. Slower than several `<link>` tags. |
| **Cascade** | How conflicts are resolved: importance, inline, specificity, then source order. |
| **Inheritance** | Text properties pass to children; box properties do not. |
| **`!important`** | Wins over normal declarations and can only be beaten by another. A deferral, not a fix. |

### Selectors and specificity

| Term | In one line |
| --- | --- |
| **Type selector** | A tag name: `p`, `table`. |
| **Class / id selector** | `.topper` (reusable) / `#result-42` (unique). |
| **Attribute selector** | `[required]`, `[type="email"]`. |
| **Descendant combinator** | A space: `table td`, at any depth. |
| **Child combinator** | `>`: `ul > li`, direct children only. |
| **Sibling combinators** | `+` the next sibling, `~` every later sibling. |
| **Pseudo-class** | One colon, a state or position: `:hover`, `:focus`, `:nth-child(2n)`. |
| **Pseudo-element** | Two colons, a part or a generated box: `::before`, `::after`. Needs `content`. |
| **Specificity** | (ids, classes, types), compared left to right. One id beats any number of classes. |

### The box and units

| Term | In one line |
| --- | --- |
| **Box model** | Content, padding, border, margin, outward. |
| **`content-box`** | The default: `width` is the content only. |
| **`border-box`** | `width` includes padding and border. Set it globally. |
| **Margin collapse** | Touching vertical margins become the larger one, not the sum. |
| **`px`** | A fixed CSS pixel. Borders and hairlines. |
| **`%`** | Of the parent. For `width`, `padding` and `margin`, the parent's width. |
| **`em`** | Of the element's font size. Compounds when nested. |
| **`rem`** | Of the root font size, 16px by default. Use for type and spacing. |
| **`vw` / `vh`** | 1% of the viewport's width / height. |

### Layout

| Term | In one line |
| --- | --- |
| **Block / inline / inline-block** | New line and full width / flows with text, ignores width / flows with text, respects width. |
| **Normal flow** | Boxes placed one after another, before any positioning. |
| **`relative`** | Offset from its normal spot, space kept. |
| **`absolute`** | Out of flow, placed against the nearest positioned ancestor. |
| **`fixed` / `sticky`** | Pinned to the viewport / sticks at an offset while its parent is on screen. |
| **`z-index`** | Stacking order of positioned elements. Higher is on top. |
| **Stacking context** | A sealed layer; children's z-index only competes inside it. |
| **Flexbox** | One-dimensional layout, a row or a column. |
| **Main / cross axis** | Along `flex-direction` / at right angles. `justify-content` / `align-items`. |
| **`flex: 1`** | Grow 1, shrink 1, basis 0: an equal share. |
| **Grid** | Two-dimensional layout, rows and columns defined up front. |
| **`fr`** | A fraction of the free space in a grid. |
| **`minmax()` / `repeat()`** | A size range / a repeated track list. `repeat(auto-fill, minmax(16rem, 1fr))`. |
| **`gap`** | Space between flex or grid items. Never collapses. |

### Responsive and theming

| Term | In one line |
| --- | --- |
| **Viewport meta tag** | `width=device-width, initial-scale=1`. Makes phones lay out at their real width. |
| **Media query** | `@media (min-width: 48rem) { … }`, rules that apply under a condition. |
| **Breakpoint** | A width where the layout changes. |
| **Mobile-first** | Base CSS for phones, `min-width` queries for wider screens. |
| **`clamp()`** | A value limited between a minimum and a maximum. |
| **Custom property** | `--brand: #1d4ed8`, read with `var(--brand)`. Cascades, changes at runtime. |
| **Transition / animation** | Between two states on a trigger / a `@keyframes` sequence on its own. |

## The pairs people confuse

::feature-list{columns="2"}
  :::feature{icon="i-lucide-git-compare" title="em and rem"}
  `em` follows the element's (or parent's) font size and compounds; `rem`
  follows the root and does not.
  :::
  :::feature{icon="i-lucide-git-compare" title="display: none and visibility: hidden"}
  Removed with no space, against invisible with its space kept.
  :::
  :::feature{icon="i-lucide-git-compare" title="relative and absolute"}
  Moved from its own spot with space kept, against taken out of flow and placed
  against a positioned ancestor.
  :::
  :::feature{icon="i-lucide-git-compare" title="Pseudo-class and pseudo-element"}
  `:hover`, a state of an element, against `::before`, a generated part of one.
  :::
  :::feature{icon="i-lucide-git-compare" title="justify-content and align-items"}
  Main axis against cross axis. They swap when the direction becomes a column.
  :::
  :::feature{icon="i-lucide-git-compare" title="Flexbox and Grid"}
  One dimension, content-sized, against two dimensions, structure first.
  :::
::

## Interview questions

::accordion
  :::accordion-item{label="Define specificity in one sentence." icon="i-lucide-message-circle"}
  A three-part score of ids, classes and types, compared left to right, that
  decides which of two conflicting rules applies to an element.
  :::
  :::accordion-item{label="Define the box model in one sentence." icon="i-lucide-message-circle"}
  Every element is a content box wrapped in padding, border and margin, and
  `box-sizing` decides whether `width` includes the padding and border.
  :::
  :::accordion-item{label="Define a breakpoint in one sentence." icon="i-lucide-message-circle"}
  The viewport width at which a media query changes the layout because the
  content no longer fits the previous arrangement.
  :::
::
