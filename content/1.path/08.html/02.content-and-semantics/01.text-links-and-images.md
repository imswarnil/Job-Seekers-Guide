The skeleton is in place: doctype, head, body. What goes inside the body is
mostly four things, and they carry most of every page you will ever build:
headings, text, links and images.

## Why this matters in a job

These elements are on every page, so the mistakes in them are on every page too.
A skipped heading level, a missing `alt`, a link that opens a new tab without
`rel="noopener"`: each is small, and each is the kind of thing a reviewer marks
in your first week. In interviews, "what is the alt attribute for?" and "what
does `target="_blank"` do, and what is the risk?" are asked of nearly every
fresher.

## Headings are an outline, not sizes

A textbook's table of contents is the analogy. Chapter 3, then 3.1, then 3.1.2.
Nobody jumps from chapter 3 to 3.1.2 with nothing in between. `<h1>` to `<h6>`
are those levels.

```html [wrong.html]
<h1>Admissions</h1>
<h4>Eligibility</h4>          <!-- chosen because h4 looked the right size -->
<h2>Fees</h2>
```

```html [right.html]
<h1>Admissions</h1>
<h2>Eligibility</h2>
<h2>Fees</h2>
<h3>Hostel fees</h3>
```

A screen reader user can list every heading on a page and jump between them,
which is how they skim. Choosing a level for its font size breaks that outline.
**Size is CSS. Level is meaning.** Use one `<h1>` per page, for the page's
subject.

## How it works

### Text and lists

```html [prospectus.html]
<h1>B.Tech Computer Science</h1>
<p>A four-year programme with <strong>120 seats</strong>.
   Classes start in <em>August</em>.</p>

<h2>Documents to bring</h2>
<ol>
  <li>Class XII marksheet</li>
  <li>Transfer certificate</li>
  <li>Four passport photos</li>
</ol>

<h2>Facilities</h2>
<ul>
  <li>Library, open until 10 pm</li>
  <li>Computer lab with 200 machines</li>
</ul>

<dl>
  <dt>CGPA</dt>
  <dd>Cumulative grade point average, on a scale of 10.</dd>
</dl>
```

```text [Rendered]
B.Tech Computer Science
A four-year programme with 120 seats. Classes start in August.
                           (bold)                      (italic)
Documents to bring
 1. Class XII marksheet
 2. Transfer certificate
 3. Four passport photos
Facilities
 • Library, open until 10 pm
 • Computer lab with 200 machines
CGPA
     Cumulative grade point average, on a scale of 10.
```

- `<ol>` is an **ordered** list: the order matters (steps, ranks).
- `<ul>` is **unordered**: a set of items.
- `<dl>`, `<dt>`, `<dd>`: a **description list** of terms and definitions.
- `<strong>` means important; `<em>` means stressed emphasis. `<b>` and `<i>`
  only change the look and carry no meaning, which is why interviewers ask for
  the difference.
- `<br>` is a line break inside a paragraph (an address, a poem). It is not for
  spacing; spacing is CSS.

### Links

```html [links.html]
<!-- Absolute: the full address, including the scheme and host -->
<a href="https://www.aicte-india.org/">AICTE</a>

<!-- Relative: resolved against the current page's address -->
<a href="faculty.html">Faculty</a>          <!-- same folder -->
<a href="/admissions/fees">Fees</a>          <!-- from the site root -->
<a href="../index.html">Back</a>             <!-- one folder up -->

<!-- A section on the same page, by id -->
<a href="#hostel">Jump to hostel fees</a>
<h3 id="hostel">Hostel fees</h3>

<!-- Other schemes -->
<a href="mailto:admissions@college.edu">Email admissions</a>
<a href="tel:+918012345678">Call the office</a>

<!-- A new tab, done safely -->
<a href="https://results.college.edu" target="_blank" rel="noopener noreferrer">
  Results portal (opens in a new tab)
</a>

<!-- Download instead of navigate -->
<a href="/prospectus-2026.pdf" download>Download the prospectus</a>
```

`target="_blank"` opens a new tab. `rel="noopener"` stops the new page reaching
back to yours through `window.opener`, which a malicious page could use to
redirect your tab to a fake login page (an attack called **tabnabbing**). Modern
browsers now imply `noopener` for `_blank`, but writing it is still expected and
still asked.

### Images

```html [images.html]
<img src="/images/campus.jpg"
     alt="The main building of the college, with students on the front lawn"
     width="800" height="450"
     loading="lazy">

<img src="/images/divider.svg" alt="">   <!-- decorative: empty alt -->
```

- `src`: where the file is. `alt`: what the image **conveys**, read aloud by a
  screen reader and shown if the image fails to load.
- `width` and `height`: the intrinsic size in pixels. The browser reserves the
  space before the image downloads, so the text below does not jump when it
  arrives. That jump has a name, **layout shift**, and Google measures it.
- `loading="lazy"`: do not download until the image is near the screen.

::tip
`alt=""` on a decorative image is correct, and different from leaving `alt`
out. Empty means "skip this". Missing means the screen reader reads the file
name, so a user hears "divider dot s v g".
::

## Real use case

A college news page in a real codebase, with each choice above made
deliberately:

```html [news.html]
<article>
  <h2>Placement drive: 42 offers from Infosys</h2>
  <p>Posted on <time datetime="2026-02-14">14 February 2026</time></p>
  <img src="/news/drive.jpg" width="1200" height="675" loading="lazy"
       alt="Students waiting outside the seminar hall for the aptitude test">
  <p>Of 310 students who sat the written round, 88 reached the interview.</p>
  <p><a href="/placements/2026">See all placement results</a></p>
</article>
```

The `<time datetime>` element gives machines (search engines, calendars) the
date in a standard format while people read it in their own. The link text says
where it goes. "Click here" as link text is a known accessibility failure,
because screen reader users often list all links on a page, and ten "click
here"s tell them nothing.

## What confuses people here

- **`alt` is not a caption and not a tooltip.** It replaces the image for
  somebody who cannot see it. The tooltip is the `title` attribute, which most
  people never see on a phone.
- **A relative link starting with `/` and one without are different.**
  `/fees` is from the site root; `fees` is from the current folder. On the page
  `/admissions/index.html`, `fees` goes to `/admissions/fees`.
- **Using `<br><br>` for space** between paragraphs. Use two `<p>` elements and
  CSS margin.

## Interview questions

::accordion
  :::accordion-item{label="What is the alt attribute for?" icon="i-lucide-message-circle"}
  It is the text alternative for an image: read by screen readers, shown if the
  image fails, and used by search engines. It should describe what the image
  conveys, not "image of". For a decorative image, `alt=""` tells assistive
  technology to skip it.
  :::
  :::accordion-item{label="Difference between strong and b, em and i?" icon="i-lucide-message-circle"}
  `strong` means important and `em` means stressed emphasis; both carry meaning
  a screen reader can convey. `b` and `i` only change the look. Default styling
  is the same (bold, italic), which is why people confuse them.
  :::
  :::accordion-item{label="What does target=_blank do, and why add rel=noopener?" icon="i-lucide-message-circle"}
  It opens the link in a new tab or window. Without `noopener`, the new page can
  access `window.opener` and change the original tab's location, a phishing
  trick called tabnabbing. `noreferrer` also hides the referring URL.
  :::
  :::accordion-item{label="Absolute versus relative URLs?" icon="i-lucide-message-circle"}
  An absolute URL includes the scheme and host (`https://college.edu/fees`). A
  relative URL is resolved against the current page: `/fees` from the site root,
  `fees` from the current folder, `../fees` one folder up.
  :::
  :::accordion-item{label="Why set width and height on an image?" icon="i-lucide-message-circle"}
  So the browser can reserve the space before the image downloads, avoiding
  layout shift. CSS can still resize it; the attributes give the aspect ratio.
  :::
  :::accordion-item{label="ol, ul and dl: when do you use each?" icon="i-lucide-message-circle"}
  `ol` when order matters (steps, rankings), `ul` for a set of items where order
  does not, `dl` for term and description pairs such as a glossary.
  :::
::
