Two chapters, in one page. The terms marked with a warning are the ones that
behave differently from the language you already know.

## The language

| Term | In one line |
| --- | --- |
| **`const` / `let`** | Block-scoped. `const` cannot be reassigned; it does not make an object immutable. |
| **`var`** | ⚠️ Function-scoped and hoisted. Recognise it in old code; never write it. |
| **`undefined`** | ⚠️ Never set. A missing property, a missing argument. |
| **`null`** | ⚠️ Deliberately empty. Two kinds of nothing, and they occur in different situations. |
| **`===`** | Compares type and value. **Use this.** |
| **`==`** | ⚠️ Converts types first. `0 == false` and `'' == false` are both true. One legitimate use: `x == null` matches both nothings. |
| **Falsy** | ⚠️ `false`, `0`, `-0`, `''`, `null`, `undefined`, `NaN`. Everything else is truthy, which is why `if (score)` is wrong for a score of 0. |
| **`??`** | Nullish coalescing. Falls back only for `null` and `undefined`, unlike `||` which also catches `0` and `''`. |
| **`?.`** | Optional chaining. `a?.b` is `undefined` rather than an error when `a` is nullish. |
| **Arrow function** | ⚠️ Has no `this` of its own, so it keeps the surrounding one. Which is nearly always what you meant. |
| **`this`** | ⚠️ In a regular function it depends on **how it was called**, not where it was written. |
| **Destructuring** | `const { name, score } = applicant`. Also works on arrays and on parameters. |
| **Spread** | `[...items, next]`, `{ ...applicant, score: 78 }`. How you copy rather than mutate. |
| **Module** | `import` / `export`. One file, its own scope. |

## Async

| Term | In one line |
| --- | --- |
| **Single-threaded** | One thread runs your code. Nothing waits, because waiting would freeze the page. |
| **Event loop** | Runs your code to completion, then the queued callbacks. Why `setTimeout(fn, 0)` runs last. |
| **Promise** | A placeholder for a value that will exist later. `pending`, then `fulfilled` or `rejected`. |
| **`async` / `await`** | Syntax over promises. `await` pauses *this function*, not the page. |
| **Microtask** | A promise callback. Runs before timers, which is the ordering question you will be asked. |
| **`fetch`** | ⚠️ Rejects only on a **network** failure. A 404 or a 500 is a successful fetch of an error, so `response.ok` is not optional. |
| **`Promise.all`** | Run several at once, fail if any fails. `allSettled` to get every result regardless. |

## The browser

| Term | In one line |
| --- | --- |
| **DOM** | The browser's live object model of the page. Reading it, changing it, listening to it. |
| **`querySelector`** | First match, or `null`. `querySelectorAll` returns all of them. |
| **`textContent`** | Text, never parsed. **Use this.** |
| **`innerHTML`** | ⚠️ Parsed as markup. With user input, this is cross-site scripting. |
| **XSS** | Injecting markup that runs. The front-end equivalent of string-concatenated SQL. |
| **Event delegation** | One listener on a container, asking what was clicked with `closest`. Works for rows added later. |
| **`event.target`** | What was actually clicked, which may be an icon inside your button. |
| **`preventDefault`** | Stop the browser's default: a form submitting, a link navigating. |
| **`dataset`** | Reads `data-*` attributes. `data-application-id` → `dataset.applicationId`. |
| **CORS** | The browser refusing a cross-origin response the server did not permit. Fixed on the **server**, not in your fetch. |

## The five sentences to keep

::pull-quote
Use `===`. Zero is falsy, so `if (score)` loses a real mark of 0. `fetch` does
not reject on a 404. Arrow functions keep the surrounding `this`. And
`innerHTML` with user input is an injection.
::
