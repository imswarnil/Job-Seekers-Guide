Every word from the track, in one page, so each one comes back as a single
clear sentence the morning of an interview. Read it top to bottom once, then
use it to test yourself: cover the right-hand column and say the line.

## Why this matters in a job

Because interviews test vocabulary before they test code. "What is hoisting?"
and "what is a closure?" are asked as definitions first, and a fumbled
definition makes the interviewer doubt the code that follows. At work, the same
words are how a reviewer explains what is wrong with your pull request.

## The language

| Term | In one line |
| --- | --- |
| **`const`** | Block scoped, cannot be reassigned. The object it holds can still change. |
| **`let`** | Block scoped, can be reassigned. |
| **`var`** | Function scoped, hoisted as `undefined`, can be redeclared. Read it in old code; do not write it. |
| **Primitive** | One of seven single, unchangeable values: number, string, boolean, undefined, null, bigint, symbol. Copied by value. |
| **Object** | Everything else: plain objects, arrays, functions, dates. Shared by reference. |
| **`undefined`** | Never set: a missing property, argument or value. |
| **`null`** | Deliberately empty, set on purpose. `typeof null` is `"object"`, a bug kept for compatibility. |
| **`NaN`** | "Not a number", the result of failed maths. A number, and not equal to itself. Test with `Number.isNaN`. |
| **Coercion** | JavaScript converting a value's type for you: `"5" - 2` is 3, `"5" + 2` is `"52"`. |
| **Falsy** | `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. Everything else is truthy, including `"0"` and `[]`. |
| **`===`** | Strict equality: same type and value, no conversion. Use this. |
| **`==`** | Loose equality: converts types first. Only idiomatic as `x == null`. |
| **`??`** | Nullish coalescing: a fallback only for `null` or `undefined`, so `0 ?? 5` is 0. |
| **`?.`** | Optional chaining: `a?.b` is `undefined` instead of an error when `a` is null or undefined. |

## Functions and scope

| Term | In one line |
| --- | --- |
| **First-class function** | A function is a value: stored, passed and returned like any other. |
| **Function declaration** | `function grade() {}`. Hoisted with its body. |
| **Function expression** | `const grade = function () {}`. Exists only after its line runs. |
| **Arrow function** | `mark => mark >= 40`. Shorter, no own `this`, no `arguments`, cannot be used with `new`. |
| **Callback** | A function passed to another function, to be called later. |
| **Higher-order function** | Takes a function, returns one, or both: `map`, `filter`, `addEventListener`. |
| **Default parameter** | `function fee(base, hostel = 0)`: used when the argument is missing. |
| **Rest parameter** | `...marks` in a parameter list: gathers arguments into an array. |
| **Spread** | `...marks` in a call or literal: unpacks an array or object. |
| **Scope** | The region of code where a name is visible: global, function or block. |
| **Lexical scope** | What a function can see is decided by where it is written, not where it is called. |
| **Scope chain** | Looking a name up in the nearest scope first, then each outer one. |
| **Shadowing** | An inner variable hiding an outer one with the same name. |
| **Hoisting** | Declarations are registered before the code runs. Assignments are not. |
| **Temporal dead zone** | The part of a scope before a `let` or `const` line, where using it throws. |
| **IIFE** | A function expression run immediately, `(function () { ... })()`, to get a private scope. |
| **Closure** | A function together with the variables of the scope it was created in, kept alive after that scope has returned. |
| **Debounce** | Wait until calls stop for a set time, then run once. A closure holding a timer. |
| **`this`** | In a regular function, decided by how it is called. Arrow functions use the surrounding one. |
| **`call` / `apply` / `bind`** | Set `this` by hand. `call` with listed arguments, `apply` with an array, `bind` returns a new function. |

## Objects, arrays and classes

| Term | In one line |
| --- | --- |
| **Destructuring** | `const { name, roll } = student`, `const [first] = toppers`. Unpacking into variables. |
| **Shallow copy** | `{ ...obj }`: new outer object, nested objects still shared. |
| **Deep copy** | `structuredClone(obj)`: nested objects copied too. |
| **JSON** | The text format for data between browser and server. `stringify` to text, `parse` back. |
| **Mutating method** | Changes the original array: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`. |
| **`map` / `filter` / `reduce`** | Transform each item / keep matching items / fold everything into one value. All return something new. |
| **`find` / `some` / `every`** | First match / is at least one true / are all true. |
| **Comparator** | The function given to `sort`: negative puts `a` first. Without one, `sort` compares as text. |
| **Prototype** | The object another object borrows properties from. |
| **Prototype chain** | The links followed when a property is not found, ending at `null`. |
| **`class`** | Syntax over prototypes. Methods live on the prototype and are shared. |
| **Module** | A file with its own scope. `export` to share, `import` to use. |

## The browser

| Term | In one line |
| --- | --- |
| **DOM** | The browser's live tree of objects built from the HTML. Change it and the screen changes. |
| **`querySelector`** | First element matching a CSS selector, or `null`. `querySelectorAll` returns all, as a static NodeList. |
| **`textContent`** | The text of an element, never parsed. Safe for user input. |
| **`innerHTML`** | The markup inside an element, parsed. Dangerous with user input. |
| **XSS** | Cross-site scripting: an attacker's markup or script running on your page. |
| **Event** | A message that something happened: click, input, submit, keydown. |
| **Event listener** | A function registered with `addEventListener` to run when an event reaches an element. |
| **Bubbling** | After the target, the event travels up through every ancestor. |
| **Capturing** | Before the target, the event travels down from `document`. Used with `{ capture: true }`. |
| **Event delegation** | One listener on a parent handles its children's events, using `event.target.closest`. |
| **`preventDefault`** | Stops the browser's default action, such as a form reloading the page. |
| **`stopPropagation`** | Stops the event travelling further through the tree. |
| **`localStorage`** | Strings kept per origin until cleared. `sessionStorage` lasts for one tab. |

## Asynchronous JavaScript

| Term | In one line |
| --- | --- |
| **Single-threaded** | One thread runs your JavaScript. Nothing waits, because waiting would freeze the page. |
| **Promise** | An object for a value that arrives later. Pending, then fulfilled or rejected, once. |
| **Callback hell** | Nested callbacks drifting right, each repeating its error handling. |
| **`async`** | Marks a function that can pause. It always returns a promise. |
| **`await`** | Pauses the current async function until a promise settles. Throws if it rejects. |
| **`Promise.all`** | Waits for all; rejects as soon as one rejects. |
| **`Promise.allSettled`** | Waits for all; never rejects; gives a status for each. |
| **`Promise.race` / `any`** | First to settle / first to fulfil. |
| **`fetch`** | The browser's HTTP function. Rejects only on network failure, never on 404 or 500. |
| **`response.ok`** | `true` for status 200 to 299. Check it after every `fetch`. |
| **CORS** | The browser only lets a page read another origin's response if that server allows it. Fixed on the server. |
| **Call stack** | Where the functions currently running are tracked. |
| **Event loop** | Runs one task, empties the microtask queue, paints, takes the next task, forever. |
| **Microtask** | A promise callback or the rest of an async function after `await`. Runs before the next task. |
| **Macrotask (task)** | A timer callback or an event handler. One per turn of the loop. |

## The pairs people confuse

These are what an interviewer probes, because they separate somebody who has
used the language from somebody who has read about it.

| Pair | The difference in one line |
| --- | --- |
| `null` / `undefined` | Set empty on purpose / never set |
| `==` / `===` | Converts types first / does not |
| `let` / `var` | Block scope, dead zone / function scope, `undefined` before its line |
| `map` / `forEach` | Returns a new array / returns nothing |
| `slice` / `splice` | Copies part / cuts the original |
| `call` / `apply` / `bind` | Runs with listed arguments / runs with an array / returns a new function |
| Shallow / deep copy | Top level only / all the way down |
| `preventDefault` / `stopPropagation` | Stops the browser's action / stops the event travelling |
| `target` / `currentTarget` | Where the event started / where the listener is |
| `Promise.all` / `allSettled` | Fails on the first rejection / never fails |
| Microtask / macrotask | All run before the next task / one per turn of the loop |

## Real use case

This page is also how you read unfamiliar code. When a pull request comment
says "this closure keeps the whole list alive" or "that `await` in a
`forEach` does nothing", each phrase maps to one row above, and the fix follows
from the definition.

## Interview questions

::accordion
  :::accordion-item{label="Define hoisting, closure and the event loop in one sentence each." icon="i-lucide-message-circle"}
  Hoisting: declarations are registered before a scope runs, so functions work
  above their line and `var` reads as `undefined`. Closure: a function keeps
  access to the variables of the scope it was created in after that scope has
  returned. Event loop: one task runs, then all microtasks, then the next task,
  forever.
  :::

  :::accordion-item{label="What is the difference between null and undefined?" icon="i-lucide-message-circle"}
  `undefined` is the language saying a value was never set; `null` is a value
  you set to mean empty. `null == undefined` is `true`, `null === undefined` is
  `false`.
  :::

  :::accordion-item{label="Difference between target and currentTarget?" icon="i-lucide-message-circle"}
  `event.target` is the element where the event started, possibly an icon
  inside a button. `event.currentTarget` is the element whose listener is
  running now. In event delegation they differ on purpose.
  :::
::
