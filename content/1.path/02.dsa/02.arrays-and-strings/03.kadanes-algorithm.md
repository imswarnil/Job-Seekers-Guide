The small idea is this: walking left to right, a running total that has gone
negative can only hurt whatever comes next, so drop it and start fresh. That
one decision turns an n² search over every range into a single pass, and it has
a name, **Kadane's algorithm**.

## Why this matters in a job

Because "maximum subarray sum" is one of the most asked array questions in
Indian coding rounds, service and product, and because interviewers use it to
see whether you can move from a brute force to an optimal solution out loud.
At work the same shape appears as "best consecutive period": the most
profitable run of days, the longest streak of improving scores, the strongest
week of admissions.

## A stretch of good and bad weeks

A student's weekly test score change against the class average is a list of
pluses and minuses: `+3, −5, +4, −1, +2, +1, −5, +4`. Which run of consecutive
weeks shows the best total improvement?

A **subarray** is a contiguous slice: consecutive elements, no gaps. The
question asks for the subarray with the largest sum.

Imagine walking the weeks carrying a bag of points. At each week you decide:
add this week to the bag I am carrying, or throw the bag away and start a new
one with this week alone. If the bag is carrying a negative total, carrying it
forward can only make things worse, so you throw it away.

## How it works

Three versions of the same answer, because in an interview you should say all
three out loud in this order.

```java [MaxSubarray.java]
public class MaxSubarray {
  // O(n³): every start, every end, add up the middle
  static int cubic(int[] a) {
    int best = Integer.MIN_VALUE;
    for (int i = 0; i < a.length; i++)
      for (int j = i; j < a.length; j++) {
        int sum = 0;
        for (int k = i; k <= j; k++) sum += a[k];
        best = Math.max(best, sum);
      }
    return best;
  }

  // O(n²): extend the sum as j moves, instead of re-adding
  static int quadratic(int[] a) {
    int best = Integer.MIN_VALUE;
    for (int i = 0; i < a.length; i++) {
      int sum = 0;
      for (int j = i; j < a.length; j++) {
        sum += a[j];
        best = Math.max(best, sum);
      }
    }
    return best;
  }

  // O(n): Kadane
  static int kadane(int[] a) {
    int current = a[0];
    int best = a[0];
    for (int i = 1; i < a.length; i++) {
      current = Math.max(a[i], current + a[i]);   // extend, or start again here
      best = Math.max(best, current);
    }
    return best;
  }

  public static void main(String[] args) {
    int[] change = {3, -5, 4, -1, 2, 1, -5, 4};
    System.out.println("cubic:     " + cubic(change));
    System.out.println("quadratic: " + quadratic(change));
    System.out.println("kadane:    " + kadane(change));

    int[] allBad = {-8, -3, -6, -2, -5};
    System.out.println("all negative: " + kadane(allBad));
  }
}
```

```text [Output]
cubic:     6
quadratic: 6
kadane:    6
all negative: -2
```

### Returning the range, not only the sum

Interviewers often follow up with "which weeks?". Remember where the current
run started, and copy it when `best` improves.

```java [KadaneRange.java]
public class KadaneRange {
  public static void main(String[] args) {
    int[] change = {3, -5, 4, -1, 2, 1, -5, 4};
    int current = change[0], best = change[0];
    int start = 0, bestStart = 0, bestEnd = 0;

    for (int i = 1; i < change.length; i++) {
      if (change[i] > current + change[i]) {
        current = change[i];
        start = i;                          // a new run begins here
      } else {
        current += change[i];
      }
      if (current > best) {
        best = current;
        bestStart = start;
        bestEnd = i;
      }
    }
    System.out.println("Best total " + best + " from week " + bestStart + " to week " + bestEnd);
  }
}
```

```text [Output]
Best total 6 from week 2 to week 5
```

### Complexity

| Version | Time | Extra space | n = 10⁵ |
| --- | --- | --- | --- |
| Three loops | O(n³) | O(1) | about 10¹⁵ steps, never finishes |
| Two loops | O(n²) | O(1) | about 10¹⁰, times out |
| Kadane | **O(n)** | **O(1)** | 10⁵, instant |

::side-note{kind="go-deeper"}
Kadane is the smallest example of **dynamic programming**: `current` is the
answer to a subproblem ("best subarray ending at i"), built from the answer to
the previous subproblem. When you reach the DP chapter, come back and read this
code again. It will look different.
::

## Real use case

::real-life{title="The best admissions fortnight" source="A college marketing team"}
Marketing wanted to know which consecutive run of days in the last admission
cycle had the highest net enquiries, counting cancellations as negatives, so
they could time next year's campaign. The data was one number per day for 180
days. A two-loop version would have been fine at that size, but the same report
was later run per course and per city across five years, and Kadane, with the
start and end days tracked as above, ran each one in a single pass.
::

## What confuses people here

- **Starting `best` at 0.** It hides the all-negative case. For `{-8, -3, -6}`
  the answer is −3, not 0, unless the problem explicitly allows an empty
  subarray.
- **Confusing subarray with subsequence.** A subarray is contiguous. A
  subsequence may skip elements. The maximum subsequence sum is the sum of all
  positives, which is a much easier problem.
- **Resetting on a negative element instead of a negative total.** `-1` in the
  middle of `4, -1, 2, 1` should be carried, because the total is still
  positive.
- **Overflow.** Use `long` when the constraints allow values near 10⁹.

## Interview questions

::accordion
  :::accordion-item{label="Find the maximum subarray sum. Walk me from brute force to optimal." icon="i-lucide-message-circle"}
  Brute force: every start and end, sum the middle, O(n³). Keep a running sum as
  the end moves, O(n²). Then observe that the best subarray ending at `i` is
  either `a[i]` alone or `a[i]` plus the best ending at `i − 1`. One pass, O(n)
  time, O(1) space. That is Kadane.
  :::

  :::accordion-item{label="What does your solution return if every value is negative?" icon="i-lucide-message-circle"}
  The largest single element, because `current` and `best` start at `a[0]`
  rather than 0. If the problem allows an empty subarray, the answer would be 0,
  and you should ask which one they want.
  :::

  :::accordion-item{label="Return the start and end indices too." icon="i-lucide-message-circle"}
  Track `start` whenever `current` restarts at `a[i]`, and copy `start` and `i`
  into `bestStart` and `bestEnd` whenever `best` improves. `KadaneRange` above
  is the full answer.
  :::

  :::accordion-item{label="Maximum circular subarray sum." icon="i-lucide-message-circle"}
  The best circular subarray either does not wrap (plain Kadane) or wraps, in
  which case it is the total minus the minimum subarray (Kadane with `min`).
  Answer `max(maxKadane, total − minKadane)`, except when every value is
  negative, where you return `maxKadane`. O(n).
  :::
::
